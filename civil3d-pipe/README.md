# DH 관로 — Civil 3D 상수 관로 애드인

지금 판 = v0.2.0 (초안 · 2026-11-27) · Civil 3D 2026 · 2027

원지반 → 평면 노선 → 종단(지장물 · 가이드안) → 구간 공법 · 지층 · 횡단 → 횡단도 · 종단도면 → 토적표 · 3D → 도면화(배치탭 납품 도면)를 한 줄로 잇는 애드인입니다.
코리더 · PKT(서브어셈블리) · 재료정의(QTO)를 쓰지 않고 **자체 단면 엔진**으로 셉니다.

## 왜 따로 만들었나

| 문제 | 원인 | 이 애드인의 방식 |
|---|---|---|
| 현장마다 터파기 단면이 달라 PKT 몇 개로 안 됨 | 단면은 «공법 × 포장 × 깊이 × 경사 × 관경 × 육상/용수»의 조합 | 구간마다 공법만 정하면 측점마다 지반 · 포장 · 지층 · 지하수위를 읽어 단면을 조립 |
| 코리더는 관로에서 보타이가 생김 | 꺾인 점 앞뒤의 직각 단면이 안쪽에서 엇갈림 | 꺾인 점에 반각 방향 단면 한 장만 — 겹칠 것이 없음 |
| 재료정의가 손이 많이 감 | 층마다 위 · 아래 면을 사람이 이어 줘야 함 | 단면을 만들 때 조각마다 이름표 → 토적표가 바로 |

## 흐름과 명령

| 단계 | 하는 일 | 명령 |
|---|---|---|
| ① 원지반 | TIN 지표면 고르기 · (부지정지 애드인이 있으면) 원지반 만들기 | `DHPIPESURF` · `DHPIPEGRADING` |
| ② 노선 | 폴리선 → Civil 선형 · 관종 · 관경 · 지표 구역(아스콘 · 콘크리트 · 보도블록 · 연석) | `DHPIPEROUTE` · `DHPIPERUN` · `DHPIPEZONE` · `DHPIPEPICK` |
| ③ 종단 | 처음 종단(토피 띠 안 최소 꺾임) → Civil 종단에서 PVI 로 설계 · 지장물 · 가이드안 · 종단도면 | `DHPIPEPROFILE` · `DHPIPEOBST` · `DHPIPEOBSTSEL` · `DHPIPEOBSTDEL` · `DHPIPEGUIDE` · `DHPIPECHECK` · `DHPIPEPROFSHEET` |
| ④ 구간 공법 · 지층 | 자연 터파기 · 조립식 · 조절식 · H-Pile+토류판 · 시트파일 · 하천 횡단 · 추진 / 지층(부지정지의 지층 구성 창 → 지층면) · 땅속 값(지층면이 없을 때) | `DHPIPEMETHOD` · `DHPIPEMETHODDEL` · `DHPIPEBORE` · `DHPIPESTRATA` |
| ⑤ 횡단도 | 측점마다 단면 + 토적표 · A1 장 나눔 | `DHPIPEXSEC` |
| ⑥ 수량 · 3D | 토적표(평균단면법) · 집계 · 공법 구간 · 관 · 부속 · 지장물 엑셀 / 터파기 · 관 · 수직구 3D | `DHPIPEQTY` · `DHPIPE3D` |
| ⑦ 도면화 | 배치탭에 평면도 · 종단면도 · 횡단면도 — 도곽 · 뷰포트 · 표제란 · 위 제목 · A1/A3 페이지 설정 | `DHPIPESHEET` · `DHPIPESHEETDEL` · `DHPIPEFRAME` |
| 창 | 오른쪽 도킹 창(단계별 상태 · 단면 미리보기 · 기준값) · 정보 | `DHPIPE` · `DHPIPEABOUT` |

리본 탭 «DH 관로»의 단추가 같은 명령을 부릅니다.

### 처음 종단
지표를 토피만큼 내리기만 하면 지표의 잔 굴곡이 모두 PVI 가 됩니다. 그래서 «최소 토피 ~ 최소 토피 + 여유» 띠를 만들고, 그 안을 곧게 갈 수 있는 데까지 가서 PVI 를 놓습니다. 여유(기본 0.8 m)를 늘리면 PVI 가 줄어듭니다. 하천 횡단 구간은 가장 낮은 땅 아래 토피로 수평, 앞뒤는 1:2 ~ 45° 경사로. 추진 구간은 수직구 안에서 수직으로 내려갑니다.

### 가이드안
공기밸브 = 종단 볼록 꼭대기 · 이토밸브 = 오목 바닥 · 제수밸브 = 시점 · 종점 · 하천/추진 횡단 앞뒤 · 긴 구간 간격 · 소화전 = 배수관일 때 간격마다(근거: KDS 57 50 00 4.1.8 ~ 4.1.10 · KDS 57 65 00 4.4.4). 자리는 제안이고, 지장물 회피만 종단을 바꿉니다(묻고 나서).

### 지층
부지정지 애드인의 [지층](시추공 · 층 · 지하수위 → 지층 지표면 «DH_지층_n_이름» · «DH_지하수위»)이 만든 면을 그대로 읽습니다. 면을 단면 선과 노선을 따라 떠서 터파기를 토사 · 풍화암 · 연암 · 보통암 · 경암으로 나누고(분류는 지표면 설명란의 값 · 없으면 층 이름으로 어림), 횡단도에는 층 선과 이름을, 종단도면에는 지층선과 지하수위선을 그립니다. 굴착면 기울기도 분류마다 다릅니다(경암 1:0.5). 지층면이 그 자리를 덮지 않으면 «땅속 값»(측점별 토사 · 풍화암 두께)으로 물러납니다.

### 도면화
부지정지 도면화와 같은 방식입니다. 종류마다 탭 하나, 장은 왼쪽에서 오른쪽으로 맞붙이고, 장마다 도곽 블록 · 뷰포트 · 표제란 글(도면명 · 도면번호 · 축척 · 날짜 · 공사명) · 위 제목 · 페이지 설정 둘(A1 1:1 · A3 맞춤)을 만듭니다. 횡단도와 종단도면은 모형 공간에 그려 둔 장을 그대로 봅니다 — 모형의 장을 도곽의 그림 자리(796 × 484 mm)에 맞춰 그리므로 그림을 통째로 옮겨도 다시 찾습니다. 평면도는 노선을 장 길이로 나눠 장마다 노선이 왼쪽에서 오른쪽으로 가게 돌려 봅니다(종단도면과 같은 측점 구간). 도곽은 부지정지와 같은 보관함(이 PC 에 저장한 도곽 → 기본 도곽 → 코드로 그리는 단순 도곽)을 씁니다. 다시 만들면 그 노선 · 그 종류의 탭만 바꿔치기하고, 탭에 직접 그린 것이 있으면 먼저 묻습니다.

### 단면 엔진
단면의 모든 경계(지반선 · 터파기 바닥과 벽 · 지층선 · 수위선 · 깊이 선 · 층 높이)를 «중심에서의 거리 → 높이» 꺾은선으로 둡니다. 모든 조각이 «아래 선과 위 선 사이»가 되어 넓이를 사다리꼴 합으로 정확히 셉니다(다각형 가위질 없음).

## 폴더

| 폴더 | 내용 |
|---|---|
| `src/DH.Pipe.Core` | 계산 엔진(Autodesk 참조 없음): 꺾은선 함수 · 지형 사본 · 단면 · 종단 · 가이드안 · 토적표 · 구간 수량 · 그림 목록 · 엑셀 · 3D 면 |
| `src/DH.Pipe.Core.Tests` | 엔진 시험(xunit) — 손 계산 값 · 실무 산출서 삽도 값과 견줌 |
| `src/DH.Pipe.Civil` | Civil 3D 층: 명령 · 리본 · 도킹 창 · 도면 저장 · 그리기 · 자가 시험 |
| `tools/preview` | 엔진 미리보기(Civil 없이 가짜 노선을 끝까지 돌려 그림 목록 · 엑셀 · OBJ) + `render.py`(PNG) |
| `tools/uishot` | 화면 밖 그리기(Civil 없이 도킹 창 · 리본 그림을 PNG 로) |
| `tools/headless` | 화면 없는 Civil 자가 시험 실행기 |
| `tools/setup` | 번들 매니페스트 · 설치 |

화면 틀(색 · 글꼴 · 둥근 창 · 도킹)과 도곽 보관함은 부지정지 애드인(`civil3d-grading`)의 `DhBrand` · `DhDock` · `DockClose` · `BusyPopup` · `ModalWatch` · `FrameLibrary` · `BundleContents` · `SheetBookRules` 를 **파일 연결**로 함께 빌드합니다. DLL 을 참조하지 않는 까닭: 두 애드인이 한 Civil 에 같이 뜰 때 같은 이름의 DLL 은 먼저 뜬 쪽 하나만 쓰이기 때문입니다.

## 빌드 · 시험 · 설치

```
dotnet test  src/DH.Pipe.Core.Tests/DH.Pipe.Core.Tests.csproj -c Release
dotnet build src/DH.Pipe.Civil/DH.Pipe.Civil.csproj -c Release                     # Civil 3D 2026
dotnet build src/DH.Pipe.Civil/DH.Pipe.Civil.csproj -c Release -p:CivilYear=2027   # Civil 3D 2027
python -X utf8 tools/setup/pkg.py                                                  # 번들 매니페스트
python -X utf8 tools/headless/run_selftest.py --year 2026                          # 화면 없는 Civil 자가 시험(2027 도 같은 방법)
dotnet run --project tools/uishot -c Release -- <출력 폴더>                         # 도킹 창 · 리본 그림 PNG
python -X utf8 tools/setup/install.py                                              # 설치(Civil 을 닫고)
```

두 판 빌드는 차례로 합니다(같이 돌리지 않음). 빌드하면 `src/DH.Pipe.Civil/DH.Pipe.bundle/Contents` 에 DLL 이 들어갑니다.

## 한계(초안)

- Civil 3D 템플릿으로 만든 도면에서 씁니다(맨 AutoCAD 도면은 종단 스타일이 없어 종단을 못 만듭니다 → 알림).
- 원지반을 «만드는» 기능은 부지정지 애드인의 명령을 부릅니다. 지표면이 이미 있으면 이 애드인만으로 됩니다.
- 한 터파기에 관 여럿(병렬)은 엔진만 됩니다(입력 화면 없음).
- 지층(시추공 · 층)을 넣는 창은 부지정지 애드인의 것을 부릅니다. 부지정지가 없으면 «땅속 값»(시추 자리의 두께 — 사이 직선 · 끝 수평)만 됩니다.
- 지층면은 부지정지가 만든 격자(가장 촘촘할 때 5 m)라, 아주 긴 노선에서는 칸이 커져 지층선이 뭉개질 수 있습니다.
- 도면화 탭에 직접 그린 것은 다시 만들기 전에 묻지만, 표제 글이나 뷰포트를 손으로 고친 것은 다시 만들면 사라집니다.
- 암층 아래에 다시 토사층이 있는 지층(차례가 뒤섞인 입력)은 그 토사층을 위의 암으로 셉니다.
- 도면화는 평면도 · 종단면도 · 횡단면도 세 가지입니다. «평면 및 종단면도»(한 장에 위 평면 · 아래 종단) · 표준 굴착 단면도 · 수량표 장은 아직 없습니다.
- 기본 도곽 DWG 는 저장소에 없습니다(빌드할 때 부지정지 번들의 `Frames` 에서 가져옴 · 없으면 단순 도곽).
- 토적표(평균단면법)와 3D 부피는 꺾인 곳에서 조금 다릅니다 — 토적표가 기준입니다.
- 평면 곡선은 1 m 현으로 나눠 셉니다(곡선마다 교각 하나 · 측점은 곡선의 시작과 끝). 반지름이 아주 작은 곡선에서는 측점이 mm ~ cm 어긋납니다.
- 측점 이름은 선형 시작 = 0 기준입니다(선형의 시작 측점을 바꾼 도면은 알림만 나옵니다).
- 종단 곡선은 꺾은선(PVI)으로 봅니다.
- 기본값 가운데 설계기준 원문을 못 본 것(관 기초 두께 · 터파기 여유폭 · 추진 수직구 크기 등)은 실무 산출서 값이며 모두 고칠 수 있습니다.
