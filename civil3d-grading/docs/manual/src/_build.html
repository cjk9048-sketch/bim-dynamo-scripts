CHAPTER 1제1장 소개 · 설치 · 업데이트

DH Grading(리본 탭 «DH 정지»)은 Civil 3D 2026 부지 정지 설계 애드인입니다. 원지반부터 옹벽 · 진입도로 · 도면 · 수량 · 3D까지 한 탭에서 합니다.

1.1 이 애드인으로 하는 일

  • 원지반 — 수치지도 · 서버 · 등고선으로 만들고 측량도로 보정
  • 계획부지 정지 — 계획 경계에서 계단식 비탈 자동 · 토공량
  • 옹벽 · 터파기 — 비탈을 옹벽으로 · 지하구조물 굴착
  • 진입도로 · 측구 — 노선 → 종단 · 사면 · 지표면 · 측구
  • 도면 · 수량 — 종단 · 횡단도, 배치 탭 도면, 수량산출서
  • 3D 보기 — 결과를 3D로 보고 공유

1.2 작업 흐름 한눈에

① 공통설정(좌표계)→② 원지반 가져오기→③ 계획부지 정지→④ 옹벽 · 터파기→⑤ 진입도로 · 측구→⑥ 종단도 · 횡단도→⑦ 도면생성 · 수량산출서→⑧ 3D 보기

처음이면 튜토리얼(13.2절)부터 해 보세요.

1.4 설치

순서

  1. Civil 3D를 모두 닫습니다.
  2. DH정지플러그인_설치_v(버전).exe를 실행합니다.
    • «PC 보호» 창이 뜨면 추가 정보 → 실행.
  3. «==== 설치 완료 ====»가 나오면 아무 키나 누릅니다.
  4. Civil 3D를 켜고 «DH 정지» 탭을 확인합니다.

주의점

  • Civil 3D가 켜져 있으면 설치가 멈춥니다. 닫고 다시 하세요.
  • 한국 좌표계 9종은 자동 설치됩니다. 안 되면 MAPCSLIBRARY로 가져옵니다.

1.5 수동 설치 · 제거

  • 수동 설치 — 수동 설치 zip의 설치.bat 실행
  • 탭이 안 보임 — DHGRADEPANEL 입력 → 안 되면 NETLOAD로 DH.Grading.Civil.dll
  • 제거 — %APPDATA%\Autodesk\ApplicationPlugins\DH.Grading.bundle 삭제

3.4 위성지도 삽입 · 지도끄기

목적

범위에 위성사진을 좌표에 맞춰 깝니다.

여는 법

순서

  1. 위성지도 추가를 누릅니다.
  2. 범위 첫 모서리를 찍습니다.
  3. 반대쪽 모서리를 찍습니다. 레이어 DH-배경지도에 깔립니다.

주의점

  • 좌표계가 없으면 안 됩니다(3.2절).
  • 지도끄기는 이 기능으로 깐 사진만 지웁니다.

3.6 지층 구성

목적

시추 자료로 지층면을 만듭니다(종단 · 횡단용).

여는 법

«공통» → 지층 구성 (DHSTRATA). 원지반이 있어야 켜집니다.

순서

  1. 입력 방식을 고릅니다(층별 GL값 / 층별 두께).

깜박이는 단추를 누릅니다. 옹벽 형식은 종횡단도를 다시 그립니다.

명령창 이유를 읽고 선을 옮기거나 수직만(V)을 고릅니다.

수량산출서가 안 만들어집니다

도면을 먼저 저장하고 횡단도를 그립니다.

Civil 3D가 작업 중 꺼졌습니다

다시 켜고 DHSELFCHECK. 진단 로그를 보내 주세요.
