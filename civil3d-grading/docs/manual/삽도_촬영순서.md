# 매뉴얼 삽도 촬영 순서 (보면서 따라 하기)

📸 **표시 = 그 화면에서 3초 멈추기.** 기록기가 그 순간을 삽도로 씁니다(괄호 = 그림 번호).
실수하면 그냥 다시 하면 됩니다 — 마지막에 찍힌 깨끗한 장면을 고릅니다.

---

## 0. 준비 (기록 시작 전)

- [ ] `메뉴얼샘플파일.dwg` 열기 · Civil 창 최대화 · 왼쪽 특성 창 닫기
- [ ] 샘플에 선 두 개 더 그려 두기
  - `터파기경계` 레이어: 구조물 바닥 외곽 닫힌 폴리선(고도 = 바닥계획고, 원지반보다 몇 m 낮게)
  - `측구선` 레이어: U형 측구 선(부지 가장자리를 따라 열린 폴리선 하나)
- [ ] 인터넷 연결 확인(위성지도 · 지적도)
- [ ] 저에게 **"시작"** → 기록기 켜짐

---

## 1. 첫 화면 · 리본

1. **DH 정지** 탭 누르기 → 📸 (1-1)
2. [계획부지 생성] 아래 화살표 펼치기 → 📸 (2-1) → Esc
3. [구조물] 아래 화살표 펼치기 → 📸 (2-2) → Esc
4. [정보] → 📸 (1-3) → Close

## 2. 공통 설정 · 배경 자료

1. [공통설정] → 창 전체 보이게 → 📸 (3-1) → 닫기
2. [위성지도 삽입] → 부지 범위 → 위성사진 깔린 화면 → 📸 (3-2)
3. [지적도] → 가져오기 → 필지 · 지번 · 소유 칠 · 범례 보이게 → 📸 (3-3)
4. [지층 구성] → 지층 4개 · 보링공 2~3개 입력 → 📸 (3-4) → 닫기
5. 위성지도 · 지적도는 이후 화면이 복잡하면 꺼 두기

## 3. 원지반 만들기

1. [원지반 가져오기] → 도킹창 전체 → 📸 (4-1)
2. [등고선으로 작성하기] → 걸침 창으로 등고선 고르는 중 → 📸 (4-5) → 완료 → 원지반 생김
3. **원지반 하나 더**(원지반 삭제 삽도용): [등고선으로 작성하기]를 한 번 더 → 원지반_2
4. [원지반 삭제] → 체크 목록 보이게 → 📸 (4-9) → **원지반_2만** 지우기
5. [원지형 자르기] → 남길 네모 찍는 중 📸 → 자른 뒤 📸 (4-10)
   - ⚠ 자르기가 부지 · 도로 범위를 넉넉히 포함하게

> 집에서 못 함(회사에서): 4-2 수치지도 DXF · 4-3/4-4 서버 · 4-6~4-8 측량도 보정

## 4. 계획부지 정지 (부지경계_1)

1. 부지경계_1 폴리선 클릭 → 특성 창 열어 고도 보이게 → 📸 (5-1) → 특성 창 닫기 · Esc
2. [계획부지 생성] → 경계 · 원지반 고르기 → «사면 설정» 펼침 → 📸 (5-2)
3. 절토 단높이 칸에 마우스 올림 → 위 설명 칸에 단면 그림 → 📸 (5-3)
4. [계획부지생성하기] → 결과 창 → 📸 (5-4) → 확인
5. 만들어진 정지면 평면(전체 보이게) → 📸 (5-5)

## 5. 옹벽

1. 창 «계획부지 수정» 탭 → 📸 (6-1)
2. [옹벽 변환] → 시안색 계단선에 마우스 올림(명령창 제원 줄 보이게) → 📸 (6-2) → 적용 → 결과 📸 (6-3)
3. [옹벽 추가] → 사면 띠 안에 점 찍는 중(주황 몸통 · «N단» 보이게) → 📸 (6-4)
   - 선을 부지 바닥 쪽으로 붙여 빨간 «부지경계 침범» → 📸 (6-5) → U로 되돌려 정상 위치
   - Enter 적용 → 결과 📸 (6-6)
4. [옹벽 삭제] → 주황 칠 · 번호 보이는 상태 → 📸 (6-7) → **Esc로 취소**(지우지 않음)
5. «옹벽» 칸 → 뒷채움 터파기 켬 → 하위 항목 보이게 → 📸 (6-8)
6. [단면 표] → 역T형 표 한 칸 클릭(치수 주황) → 📸 (6-9) → 닫기

## 6. 구조물 터파기 · 박스 구조물

1. [구조물 터파기] → 창 전체 → 📸 (7-1)
2. `터파기경계` 선 고르기 → 구배 입력 → [터파기 지표면 생성] → 결과 평면 📸 (7-2)
3. 가시설 [부분 변환] → 둘레 한 구간 → 파란 띠 → 📸 (7-3)
4. [구조물] ▾ → [박스 구조물] → 창 + 평면 박스 외곽 → 📸 (7-5)

> 7-4(Revit 구조물)는 Revit DWG가 있을 때만

## 7. 진입도로 (도로가이드 · 부지경계_2)

1. [진입도로 생성] → 창 전체(노선 ~ 결과) → 📸 (8-1)
2. [경로 그리기] → 점 찍는 중(커서 옆 안내 보이게) → 📸 (8-2)
   - 가이드선을 쓰면 그 선을 따라 찍기
3. [진입도로 생성] → 생성 직후 평면 → 📸 (8-3)
4. 진입도로 종횡단도 창 «종단도 생성» 탭 → 📸 (8-4)
5. [측점 넣기] → 계획 종단선 고름(PVI 그립 보이게) → 📸 (8-5)
6. «진입도로 수정» 탭 → 📸 (8-6)

## 8. 측구

1. 진입도로 «측구» 칸 → [측구 단면…] → U형 · 안폭 칸 클릭 → 📸 (9-1) → L형 고르기 → 📸 (9-2) → 닫기
2. 리본 [U형 측구] → 창 전체 → 📸 (9-3)
3. [선 고르기] → `측구선` → [도면에서 보기] → 빨간 선 → 📸 (9-4)
4. «강우» 칸 [CSV…] → IDF 표 불러오기 → 📸 (9-5)  *(CSV 없으면 건너뜀)*
5. [면적 고르기]로 집수 면적 → «결과» 칸 · 구간 표 → 📸 (9-6)
6. [모델 생성] → 3D 궤도(Shift+휠 끌기)로 솔리드 → 📸 (9-7) → 평면도로 돌아오기

## 9. 종단도 · 횡단도 (계획부지)

1. [종횡단도] → «종단도 생성» 탭 → 📸 (10-1)
2. [종단도 생성] → 부지를 가로지르는 노선 그리는 중 → 📸 (10-2)
3. 그려진 종단면도로 이동 → 📸 (10-3)
4. «횡단도 생성» 탭 → 📸 (10-4) → 생성
5. 그려진 횡단면도(토량표 포함) → 📸 (10-5)

## 10. 도면생성 · 수량산출서 · 대안

1. [도면생성] → 창 전체 → 📸 (11-1) → [작성하기]
2. «부지 횡단면도» 배치 탭 → 📸 (11-2)
3. «전체 계획평면도» 탭 + «평면 꾸미기» 창 → 📸 (11-3) → 모형 탭으로
4. [수량산출서] → 창 전체 → 📸 (11-4) → [만들기]
5. 엑셀 «토공집계표» 시트를 **Civil 창 자리에 최대화** → 📸 (11-5) → 엑셀 닫기
6. [대안] → 대안 2~3개 저장(계획고를 조금씩 바꿔) → 나란히 보이게 → 📸 (11-6)

## 11. 3D 보기

1. [3D 보기] → 위성 위 부지 · 비탈 · 옹벽 · 도로 비스듬히 → 📸 (12-1)
2. «레이어» → «절성토 깊이» 켬 → 📸 (12-2)
3. [저장] 메뉴 펼침 → 📸 (12-3) → 3D 창 닫기
   - 3D 창은 **Civil 창 위에** 띄워 주세요(기록 범위)

## 12. 초기화 · 튜토리얼 (맨 마지막)

1. [전체 초기화] → 확인 창 → 📸 (13-1) → **취소**(초기화하지 않음)
2. [튜토리얼] → 단원 고르기 창 → 📸 (13-2)
3. 한 단원 시작 → 강조된 단추 화면 → 📸 (13-3) → 튜토리얼 끝내기
