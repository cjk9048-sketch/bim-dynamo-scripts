계획 폴리곤(평지 경계)을 그려두면, 그 가장자리에서 바깥쪽으로
**5m 정지 → 1m 소단 → 5m 정지 → 1m 소단 …** 을 반복하다가
**원지반(원래 땅)과 만나는 곳에서 자동으로 멈추는 계단식 비탈면**을
하나의 TIN Surface로 만들어 주고, **절토·성토량(m³)** 까지 계산합니다.

> **왜 코리더를 안 쓰나?** 코리더는 경계가 꺾이는 코너에서 단면이 겹쳐 보타이(X자 꼬임)가 생깁니다.
> 이 도구는 코리더 대신 **"경계에서 떨어진 거리"만으로 단을 만드는 distance-field 방식**이라
> 오목·볼록 코너에서 면이 절대 꼬이지 않습니다.

## 화면 — 도킹창 둘, 팝업 하나 (v73.0)

설정은 **오른쪽에 붙는 도킹창**에서 합니다. 창을 띄워 둔 채로 도면을 보며 값을 고칩니다.

| 리본 단추 | 명령 | 무엇 |
|---|---|---|
| **정지 창** | `DHGRADEPANEL` | 계획 경계·원지반 선택 → 지표면 생성 · 절성토 제원(예시 그림) · 산지 대소단 · 옹벽 형태 · **사면 수정** |
| **터파기 창** | `DHEXCAVPANEL` | **기준면**(계획지표면/원지반) 선택 · 터파기선 선택 → 생성 · 굴착 구배 · **가시설 구간** |
| 기타 → **기타 설정** | `DHMISCSET` | 좌표계(내보내기 원점) · 결과지표면만 표시 |

`DHGRADESET`(옛 [정지 옵션])은 **정지 창을 엽니다** — 이름은 손에 익어서 남겨 뒀습니다.

### 그 밖의 명령

| 명령 | 무엇 |
|---|---|
| `DHGRADE` | 계획부지 정지 — 폴리곤·원지반을 명령창에서 골라 만듭니다(창을 안 쓰는 길) |
| `DHEXCAV` | 구조물 터파기 — 위와 같은 방식 |
| `DHWALL` / `DHSLOPE` | 옹벽 변환 / 사면 변환 (정지 창의 [사면 수정] 단추가 이것을 부릅니다) |
| `DHEXCAVWALL` / `DHEXCAVSLOPE` / `DHEXCAVWALLCLEAR` | 가시설 구간 지정 / 해제 / 전체 해제 |

구배 표기 **1:n = 수직 1 : 수평 n** (예 `1:1.5` = 수직 1m 올라갈 때 수평 1.5m). 절토·성토 각각 지정합니다.

## 사용 순서

1. 계획면 경계를 **닫힌 폴리라인**으로 그립니다. 폴리라인의 **표고(Z)가 계획고**입니다.
   - 2D 폴리라인은 Elevation 한 값, 3D 폴리라인·피처라인은 정점별 Z를 씁니다.
2. 원지반을 **Civil 3D TIN Surface**로 준비합니다.
   ([기타]의 [서버 지표면] 또는 [수치지도 DXF]로 만들 수 있습니다.)
3. 리본 **[정지 창]** → [계획 경계 선택] → [원지반 선택] → **[지표면 생성]**.
   값을 고쳤으면 **[값 저장]**을 눌러야 다음 생성에 반영됩니다.
4. 결과는 **`정지면_DH`** 입니다. 절토·성토·순토공량이 명령창과 팝업에 나옵니다.
5. 지하구조물이 있으면 리본 **[터파기 창]**:
   - **기준면**을 고릅니다 — 계획지표면(계획고까지 성토·다짐 후 터파기) 또는 원지반(터파기 먼저).
     **공정에 따라 다르고, 토공 수량이 달라집니다.**
   - [이 면만 보기]로 그 면 위에서 구조물 바닥 폴리선을 그립니다.
   - [터파기선 선택] → **[터파기 지표면 생성]** → `터파기면_DH`.
   - 둘레 일부만 흙막이를 세우려면 **[가시설 변환]** — 자리를 찍고 구간 길이를 줍니다.

절토/성토는 위치별 자동 판별: 계획고가 원지반보다 **높으면 성토**(아래로 비탈), **낮으면 절토**(위로 비탈).
한 폴리곤에서 한쪽 절토·다른 쪽 성토도 자동 처리됩니다.

```

  ```

## 동작 원리(요약)

격자(기본 1m)의 각 점에서 가장 가까운 경계점까지의 **바깥 거리 d**를 구하고,
`d`에 따라 계단 프로파일(`5n m 비탈 → 1m 소단 → 반복`)만큼 계획고에서 올리거나 내립니다.
원지반과 만나는 지점에서 잘라(daylight) 정지 영역을 확정합니다.
거리 `d`는 코너에서도 항상 한 값으로 정의되므로 면이 겹치지 않습니다.

> 토공량은 Civil3D 체적 표면(`TinVolumeSurface`)으로 정밀 산출하며,
> 실패 시 격자 기반 근사값으로 대체합니다. 격자 해상도를 낮추면(0.5m) daylight 경계가 더 매끈해집니다.
