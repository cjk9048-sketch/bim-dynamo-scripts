# 종단·횡단 자동 생성 기능 — 기본계획 (2026-07-31)

JACK 확정 사항: **종단+횡단 둘 다** · **원지반+정지면 둘 다 표시** · **간격/폭은 정지옵션 기본값** · **배치는 클릭한 위치**

---

## 1. 개념

정지면 위에 **선 하나만 그으면** 그 선을 따라 종단면도와 횡단면도가 자동 생성된다.
직접 그림을 그리는 게 아니라 **Civil3D 정식 객체**(선형·종단·측점선·단면뷰)로 만들기 때문에:

- 정지면을 수정하면 종단·횡단이 **자동 갱신**
- Civil3D 기본 라벨·토공량·도면출력 기능을 그대로 사용
- 원지반·정지면이 한 도면에 겹쳐 나와 **절토/성토 구간이 한눈에** 보임

## 2. API 가용성 확인 (apiprobe로 실측, 2026-07-31)

AeccDbMgd.dll(Civil3D 2026) 리플렉션 조사 결과 — 필요한 API 전부 존재:

| 단계 | API | 비고 |
|---|---|---|
| 선 → 선형 | `Alignment.Create(CivilDocument, PolylineOptions, name, siteId, layerId, styleId, labelSetId)` | `PolylineOptions{ PlineId, EraseExistingEntities, AddCurvesBetweenTangents }` |
| 지표면 종단 | `Profile.CreateFromSurface(name, alignmentId, surfaceId, layerId, styleId, labelSetId)` | 오버로드에 sampleStart/End 있는 버전도 존재 |
| 종단도 | `ProfileView.Create(alignmentId, insertPosition)` | 이름·밴드셋·스타일 지정 오버로드 있음 |
| 측점선 그룹 | `SampleLineGroup.Create(groupName, alignmentId)` | |
| 측점선 | `SampleLine.Create(name, groupId, station)` / `(name, groupId, Point2dCollection)` | **폭 제어는 Point2dCollection 방식** |
| 표본 지표면 지정 | `SampleLineGroup.GetSectionSources()` → 각 `SectionSource.IsSampled = true` | Set 메서드 없음 = 라이브 컬렉션 수정 방식 |
| 횡단도 | `SectionView.Create(sectionViewName, sampleLineId, location)` | |

## 3. 사용 흐름 (사용자 관점)

1. 정지면 위에 검토하고 싶은 노선대로 **폴리선을 하나 그린다**
2. 리본 [도면화] → **[종단/횡단]** 클릭
3. 그린 선을 클릭
4. "종단도 놓을 위치" 클릭 → 종단면도 생성
5. "횡단도 놓을 위치" 클릭 → 횡단면도들 격자 배치
6. 끝 (간격·폭은 정지옵션 값 자동 적용)

## 4. 내부 처리 순서

```
① 게이트: 정지면_DH 존재 확인 (없으면 안내 후 중단)
② 선 선택 (폴리라인 2D/3D — 사용자가 방금 그린 선)
③ Alignment 생성
     PolylineOptions{ PlineId=선, EraseExistingEntities=false }  ← 사용자 선 보존
     이름 "DH선형_N"(중복 회피), site=ObjectId.Null(무사이트), 레이어 DH-종단선
④ 지표면 2개 확정
     원지반 = 번들 GroundHandle → 없으면 DHINFRA와 동일한 자동선택(DH 산출물 제외 최다삼각형)
     정지면 = 정지면_DH
⑤ Profile.CreateFromSurface × 2  ("DH_원지반", "DH_정지면")
     스타일: 존재하는 것 중 선택, 없으면 기본 폴백(SetSurfaceStyle 패턴 재사용)
⑥ 위치 클릭 → ProfileView.Create
⑦ SampleLineGroup.Create("DH횡단_N", alignmentId)
     GetSectionSources() 순회 → 원지반·정지면만 IsSampled = true
⑧ 측점선: station 0 → 끝까지 간격마다
     Alignment로 중심 좌표·법선 계산 → 좌/우 폭 지점 2점 → SampleLine.Create(name, groupId, Point2dCollection)
     (폭을 확실히 제어하기 위해 station 오버로드 대신 좌표 방식 채택)
⑨ 위치 클릭 → 측점선마다 SectionView.Create, 격자 배치(가로 N개씩, 뷰 크기+여백 간격)
```

## 5. 정지옵션 추가 항목

| 항목 | 기본값 | 설명 |
|---|---|---|
| 횡단 간격 | 20 m | 측점선을 몇 m마다 놓을지 |
| 횡단 폭(좌) | 30 m | 중심선 왼쪽으로 자를 폭 |
| 횡단 폭(우) | 30 m | 중심선 오른쪽으로 자를 폭 |
| 횡단도 열 수 | 3 | 횡단면도를 가로로 몇 개씩 배치할지 |

## 6. 명명 규칙 · 초기화 연계

- 선형 `DH선형_N` / 종단 `DH_원지반`·`DH_정지면` / 측점선그룹 `DH횡단_N` / 레이어 `DH-종단선`
- **DHRESET(초기화)** 확장: 위 이름 규칙의 선형·종단·측점선그룹·뷰도 함께 삭제
  (현재 초기화는 `DH-` 레이어 객체 + 정지 지표면만 지움 → Civil3D 객체는 이름 기반 삭제 추가 필요)

## 7. 리스크 · 대응

| 리스크 | 대응 |
|---|---|
| `SampleLine.Create(Point2dCollection)` 점 순서·개수 규약 불명 | 1단계 실기에서 좌2점 방식 검증, 실패 시 station 오버로드 폴백 |
| 종단도/횡단도 스타일이 템플릿에 없으면 생성 실패 | 기존 `SetSurfaceStyle` 폴백 패턴 재사용(존재하는 스타일 탐색 → 기본) |
| 한국어판 스타일명 상이 | 영문/한글 후보 병행 탐색(기존 등고선 스타일에서 검증된 방식) |
| 선이 정지면 밖으로 나감 | 종단은 지표면 없는 구간 자동 제외됨 — 경고만 표기 |
| 선형 생성 시 기존 동명 객체 충돌 | `UniqueName` 패턴으로 회피(기존 지표면 로직 재사용) |

## 8. 단계별 진행 (검증 단위)

- **1단계**: 선형 + 종단 2개 + 종단도 → JACK 실기 확인
- **2단계**: 측점선(폭 검증) + 횡단도 격자 배치 → JACK 실기 확인
- **3단계**: 정지옵션 통합 + 초기화(DHRESET) 연계 + 리본 버튼·툴팁 마감

각 단계마다 검토 에이전트 패스 후 설치(기존 규칙 동일).
