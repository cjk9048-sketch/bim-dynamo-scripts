JACK 1125 저녁 «남은 거 전부 수행하고 설치하고 커밋 푸시해» → 아래 전부 했음.

## 1. 바로 해 볼 것 (5분)

1. 바탕화면 **드론 로드뷰** → 처음 화면 «최근 프로젝트» 의 **«394장 (보통)»** 열기 → 3D 보기
   - 끌기 = 돌리기 · 오른쪽 끌기 = 옮기기 · 휠 = 확대 · 두 번 = 그 점으로 · [위에서 보기]
2. **[결과물]** → 정사영상 · DSM · **DTM** · 지표면(DSM · **DTM**) · 정보.txt
3. Civil 3D 에서 **지표면_DTM.xml** 가져오기 (원지반용) — 좌표 EPSG:5186 · 표고 EGM2008
4. (있으면) 검사점 파일(이름, X, Y, 표고) → 3D 보기 **[검사점]** → 점 고르고 모델에서 찍기 → **[보고서 저장]**
5. 새로 만들기: 처음 화면 **[3D 매핑]** → 사진 폴더 → [범위 그리기] → 좌표계 · 품질 → [만들기]

## 3. 내가 정한 것

- **좌표계 기본 = 중부원점(5186)**: 회사 도면 · 그레이딩 · 로드뷰가 5186 이라 맞춤. 동부 · 서부 현장은 매핑 화면에서 고름.
- **DTM = 점진형 형태학 필터 (OpenCV)**: 설계서는 PDAL 이지만 설치본에 이미 있는 OpenCV 로 — 설치 크기 · 새 의존성 없음.
  사진(RGB)만으로는 숲 밑 땅을 모름 → 메운 곳을 «DTM_땅칸.tif = 0» 으로 따로 표시 (설계서 6.1).
- **검사점 = 확인만 (GCP 로 모델을 고치지는 않음)**: RTK 로 이미 0.13 m · 검사점과 GCP 는 따로 (설계서 6.4).
- **질감 조각 한 변 최대 8192**: 대부분 그래픽카드 16384 지원이지만 오래된 내장 그래픽 · 시험 렌더러가 8192.
