## 1. 바로 해 볼 것 (5분)

1. 바탕화면 **드론 로드뷰** → 처음 화면 «최근 프로젝트» 의 **«394장 (보통)»** 열기 → 3D 보기
   - 끌기 = 돌리기 · 오른쪽 끌기 = 옮기기 · 휠 = 확대 · 두 번 = 그 점으로 · [위에서 보기]
2. **[결과물]** → 정사영상 · DSM · **DTM** · 지표면(DSM · **DTM**) · **점구름.las** · 정보.txt
3. Civil 3D 에서 **지표면_DTM.xml** 가져오기 (원지반용) — 좌표 EPSG:5186 · 표고 EGM2008
4. 새로 만들기: 처음 화면 **[3D 매핑]** → 사진 폴더 → [범위 그리기] → **만들 것** (기본 = 3D 모델만) · 좌표계 · 품질 → [만들기]
5. 나중에 더 만들기: 같은 사진 · 같은 결과 폴더로 다시 [만들기] → 고른 것만 더 만듦 (앞 단계 · 3D 는 다시 안 함)

## 5. 내가 정한 것

- **만들 것 기본 = 3D 모델만**: JACK «주로 3D 매핑» · 고른 것은 다음에도 기억.
- **3D 만 점구름 = 한 단계 덜 촘촘**: 가장 오래 걸리는 단계 · 겉모습은 질감이 정함 → 80장 2.8배 빠름 · 견줌 그림 거의 같음.
  측량용 결과물(정사 · DSM · DTM · LAS)은 늘 측량용 해상도 (정확도 안 깎음).
- **나중에 더 만들 때 3D 는 그대로**: 측량용 점구름만 따로 더 만듦.
- **LAS 도 고르기에 넣음**: 처음 인터뷰에선 안 고르셨지만 «포인트클라우드» 말씀이 있어 넣음 (기본은 꺼짐).
- **좌표계 기본 = 중부원점(5186)**: 회사 도면 · 그레이딩 · 로드뷰가 5186.
- **DTM = 점진형 형태학 필터 (OpenCV)**: 설치본에 이미 있는 것으로 (새 의존성 없음). 사진만으로는 숲 밑 땅을 모름 → 메운 곳 따로 표시.
- **검사점 = 확인만 (GCP 로 모델을 고치지는 않음)**: RTK 로 이미 0.13 m.
