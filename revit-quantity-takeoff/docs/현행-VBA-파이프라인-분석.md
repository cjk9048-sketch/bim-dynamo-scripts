## 0. 신규 프로그램의 방향 (사용자 확정 2026-06-04)

**수식까지 Revit에서 해결** — 애드인이 ① 형상별 토큰 수식 부여 + ② **안목·총길이가 반영된
net 치수까지 공급**한다. 따라서 **Excel `Calc_Sheet`(안목/총길이 파생)는 불필요 → 애드인이 흡수**.
VBA는 토큰 치환 + 산출근거 레이아웃만 담당. (지오메트리 자동 공제 = 안목 산출과 동일 작업)

## 2. CSV_Import (Revit 원시 치수)
열: `DH_ElementCode, DH_Class, DH_Category, L1, L2, L3, W1, W2, W3, H, ETC, DH_Zone, DH_Part, ElementID`
- 312행 **전부 Body**(이 모델엔 Sub 공제행 0개). 33개 코드.
- 코드: `C1, C1_ColNum, C1_RowNum, B1~B4, S1, S2, MS1, TC1~TC3, L1~L4, W1~W10, H1~H4, P1, G1`.
  (`C1_ColNum/RowNum` = 기둥 열·행 개수 보조, ETC에 개수 기입. `P1`=PIT.)

## 3. Formula (★ 자동화 대상) — 공종 15개
A열 = 부재코드(HostID). 1행 공종 헤더:
`B 무근콘크리트 | C 철근콘크리트 | D 거푸집(합판6회) | E 거푸집(합판4회) | F 거푸집(합판3회) |
G 유로폼 | H 시스템비계 | I 강관조립말비계(이동식) | J 강관동바리 | K 시스템동바리 |
L 방수 | M 콘크리트표면마무리 | N 콘크리트양생 | O 콘크리트치핑`

각 코드는 해당 공종 컬럼에만 수식을 채움(대부분 콘크리트 1 + 거푸집 1~2). 실관측 수식:

| 코드 | 콘크리트 | 거푸집 등 |
|------|----------|-----------|
| L1(버림) | `([L1]*[W1]+[L2]*[W2]+[L3]*[W3])*[H]` | 합6 `([W1]+[L1_L_Long]+[W3])*[H]` |
| L3 | `([W1]+[W2])*[H]*1/2*([L1]*2+[L2]*2+[L3])` | 합6 `([L1]*2+[L2]*2+[L3])*[H]` |
| B1(기초) | `([L1]*[W1]+[L2]*[W2]+[L3]*[W3])*[H]` | 합3 `([W1]+[B1_L_Long]+[W3])*[H]` |
| S1(슬래브) | `[L1]*[W1]*[H]` | 합4 `[S1_W_Form]*[S1_L_Form]` |
| S2 | `[L1]*[W1]*[H]` | 합4 `[S2_BW_Form]*[S2_BL_Form]+[S2_EW_Form]*[S2_EL_Form]` |
| TC1~3(마침) | `[L1]*[W1]*[H]` | 합6 `([W1]*2+[L1]*2)*[H1]` |
| C1(기둥+헌치) | `[L1]^2*[C1_Up]+([C1_Bottom]^2+[L1]^2)*1/2*[ETC]` | 합3 `([L1]+[C1_Bottom])*1/2*[C1_H_Form]*4+[L1]*[C1_Up]*4` |
| G1(보) | `[L1]*[W1]*[H]` | 합3 `[L1]*[H]*2` |
| W1~W10(벽) | `[L1]*[H]*[W1]` | W1 합3 `(내측)#[L1]*[H]\|(외측)#[L1]*[H]` |
| **L2_Sub** | **`-([L1]*[H]*[W1])`** | — |

### 3.1 수식 토큰·문법 (VBA 파서 — 확정)
- 토큰: 원시 `[L1]`,`[W1]`,`[H]`,`[ETC]` + Calc_Code `[L1_L_Long]`,`[S1_W_Form]`,`[C1_Up]` 등.
- `|` = 다중 패턴, `#` = 라벨#수식, `^2`/`SQRT()`/`PI()`/`*1/2` 지원.
- **★ 공제 = 음수 수식 네이티브 지원**: `L2_Sub = -([L1]*[H]*[W1])`. 코드에 `_Sub` 접미
  (DH_Class=Sub) → VBA가 별도 음수 행으로 출력, `=SUM` 소계에서 차감. **부호/별도행 둘 다 정상**.

## 4. Calc_Sheet (신규 프로그램이 애드인으로 대체) — 정체 = '안목 계산'
단순 파생이 아니라 **벽두께를 뺀 안목(clear-span)·총길이·헌치빗변** 계산:
- 총길이: `L1_L_Long = ΣL1+L2+L3`(코드 L1), `L1_W_Long = W1*2`.
- **안목**: `S1_L_Inner = S1길이 − W3 − W4`, `S1_W_Inner = S1폭 − W1 − W6/2`.
- 거푸집길이: `S1_L_Form = S1_L_Inner − 헌치(B20)*2`.
- 헌치: `H1_haunch = H1의 W1`, `H1_Form = ROUND(√(h²+h²),2)`(빗변), `C1_Up/Bottom/H_Form`(기둥헌치).
→ **이 계산들은 전부 지오메트리(겹침·벽두께·헌치)로 산출 가능 → 애드인이 net 치수로 공급**하면 불필요.

## 5. Quantity_Report (골든 출력)
- 공종별 블록(무근콘크리트/철근콘크리트/…) → `ㅇ 부재` → `코드 : (수식 셀 전개) = ROUND값` → `계 : =SUM`.
- 예) C1 기둥 `=ROUND((G30^2*K30+(O30^2+S30^2)*H32/K32*N32*Q32),2) ⟶ 0.45`
  (= 0.3²×4.95, ETC=0이라 헌치항 0). L1 슬래브 `⟶153.02`, 무근 계 `278.53`.
- → **AC-11 골든 비교의 기준본**.

## 6. 신규 애드인 출력 계약 (Option 1 = 수식까지 Revit 해결)

1. **CSV**: 14열, **UTF-8 BOM**. L1~H에는 **안목·겹침 반영된 net 치수**를 기록(애드인이 지오메트리로 산출).
2. **Formula 공급**: 애드인이 형상별 토큰 수식을 **객체 공유매개변수(DH_수식_<공종>)** 에 부여 →
   export가 코드별 1행으로 formula 시트 재구성(15개 공종 컬럼). **Calc_Code 토큰 미사용**(net 치수가
   이미 안목 반영) — 단, 기존 호환 위해 Calc_Code도 pass-through 옵션 유지.
3. **공제 표현**: ⓐ 선형 안목 → net 치수에 반영. ⓑ 비선형(개구부 등) → **`_Sub` 음수행**(L2_Sub 패턴,
   현행 네이티브)으로 emit. **새 토큰 불필요**.
4. **Calc_Sheet**: 신규 경로에선 미사용(애드인이 net 공급). 기존 워크북 호환 위해 비워두거나 유지 가능.

### 6.1 객체 공유매개변수 → formula 시트 셀 매핑
| 원천 | → | formula 시트 |
|------|---|--------------|
| `DH_ElementCode` | → | A열 행 키(코드당 1행) |
| `DH_수식_무근콘크리트` | → | B열 |
| `DH_수식_철근콘크리트` | → | C열 |
| `DH_수식_거푸집6/4/3` | → | D/E/F열 |
| `DH_수식_<기타공종>` | → | G~O열(유로폼·비계·동바리·방수·마무리·양생·치핑) |

규칙: 코드당 1행, `|`/`#` 보존, 코드중복(다른 수식) 경고+첫항, 빈수식 미처리목록, 음수 `_Sub`는 별도 행.
