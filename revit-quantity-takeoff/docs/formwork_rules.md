# 거푸집·체적 산정 기준 (기본값)

`scripts/takeoff/calc.py` 에 구현된 기본 산정식입니다. **회사/표준품셈 기준에 맞게
조정**하세요. 모든 치수 단위는 미터(m)입니다.

| 카테고리 | 콘크리트 체적 (m³) | 거푸집 면적 (m²) | 비고 |
|----------|-------------------|------------------|------|
| 기둥 Columns | `b × h × 높이 × 개수` | `2×(b+h) × 높이 × 개수` (4면) | 보·슬래브 접합부 공제 생략 |
| 보 StructuralFraming | `b × h × 길이 × 개수` | `(2h + b) × 길이 × 개수` (양측면+바닥) | 상부 슬래브면 제외 |
| 기초 Foundations | `B × L × H × 개수` | `2×(B+L) × H × 개수` (측면 4면) | 상·하부 거푸집 제외 |
| 슬래브 Floors | `면적 × 두께 × 개수` | `면적 + 둘레×두께` (둘레 입력 시) | 둘레 미입력 시 하부면만 |
| 벽 Walls | `길이 × 높이 × 두께 × 개수` | `2 × 길이 × 높이 × 개수` (양면) | 개구부 공제 미반영 |

## 부재 교차부 겹침 공제 (지원됨)

부재가 서로 물리는 **겹침길이**만큼 유효치수로 콘크리트·거푸집·길이를 계산합니다.
**산출식에는 순(net) 치수만** 나오고, 공제 내역은 **비고**로만 남깁니다.

| 카테고리 | 공제 입력 키 | 적용 | 산출식 예 (비고) |
|----------|-------------|------|------------------|
| 기둥 Columns | `deduct_height` | 높이에서 공제 (보춤 등) | `0.5×0.5×3.0×2` (겹침 0.6m 공제) |
| 보 StructuralFraming | `deduct_length` | 길이에서 공제 (양단 기둥 물림 합) | `0.4×0.7×5.1×12` (겹침 0.9m 공제) |
| 벽 Walls | `deduct_length` | 길이에서 공제 (교차 기둥 등) | `2×4.5×3.6×6` (겹침 0.5m 공제) |

- 공제값은 **양단 겹침의 합(m)**. 공제 후 치수가 0 이하면 `CalcError`.
- 공제 0/미입력이면 기존과 동일(하위호환).

## 겹침은 '한 번만' — 우선순위 귀속 (중요)

두 부재가 겹치는 구간은 **정해진 우선순위가 높은 부재 하나에만 귀속**되어 그대로
포함되고, 낮은 부재에서만 공제됩니다. 처리 '순서'가 아니라 '우선순위'로 결정하므로
입력 순서와 무관하게 **정확히 한 번** 계산됩니다(중복·누락 방지).

기본 우선순위 (`overlap.DEFAULT_PRIORITY`, 숫자 작을수록 소유):

| 순위 | 카테고리 | 의미 |
|------|----------|------|
| 0 | 기초 Foundations | 기둥-기초 접합부 소유 (기둥이 높이 공제) |
| 1 | 기둥 Columns | 보-기둥 접합부 소유 (보가 길이 공제) |
| 2 | 벽 Walls | |
| 3 | 보 StructuralFraming | |
| 4 | 슬래브 Floors | |

- `runner.run(..., overlaps=[{"a": i, "b": j, "length": m}, ...])` 로 부재 쌍의 겹침을
  넘기면 `overlap.resolve_overlaps` 가 우선순위로 공제를 귀속합니다.
- 겹침 길이는 Dynamo 조인트 탐지(`docs/dynamo_joint_detection.py`)에서 자동 산출.

### 아직 수동 처리 항목

- **슬래브–보**: 슬래브는 선형 공제 대상이 아니어서(우선순위 최하위) 보와의 겹침이
  자동 공제되지 않음 → 입력 `area`/`thickness` 를 안목값으로 조정하거나 향후
  `deduct_volume`/`deduct_formwork` 지원으로 처리 예정.
- **벽 개구부(창·문)**: 입력 `length`/`height` 조정 또는 향후 면적/체적 공제 지원.

## 단위·정밀도

- 입력: m, m² (Revit 내부 피트 → Dynamo 노드에서 `×0.3048` 변환)
- 출력: 콘크리트/거푸집/길이 소수 3자리, 수량 정수
