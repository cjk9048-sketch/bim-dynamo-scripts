# Revit 수량산출 자동화 — 기획·설계 문서 (검토용)

> Revit 2026 구조 모델 → 객체 순회 → **산출근거 포함 엑셀 수량산출서** 자동 생성.
> 본 문서는 결정사항·구조·산정규칙·로드맵을 검토하기 위한 요약입니다.

## 1. 목표

- Revit 구조물의 객체를 하나씩 순회하며 **2D 수량산출서(BOQ)** 형태의 엑셀 생성.
- 각 행에 **산출근거(산출식)** 포함.
- 기존 "채팅→생성→Dynamo 실행→실패 시 스샷→재수정" 루프를 **파일 기반**(로그/모듈
  직접 수정)으로 전환해 반복 비용 절감.

## 2. 확정된 범위 (인터뷰 결과)

| 항목 | 결정 |
|------|------|
| 작성 도구 | **Dynamo for Revit (Python 노드, CPython3)** — Revit 2026 |
| 대상 부재 | 기둥 / 보·거더 / 기초 / 슬래브·벽 (4종) |
| 산출 항목 | 콘크리트 체적(m³) / 거푸집 면적(m²) / 부재 수량(EA)·길이(m) — *철근 제외* |
| 산출근거 | 산출식 + 계산값. **겹침은 식에 미표기**, 비고로만 |
| 겹침 처리 | 부재 교차부 **공제**(중복 제거). 우선순위로 **한 번만** 계산 |

## 3. 아키텍처

```
Revit 2026 모델
  └─ Dynamo Python 노드 (CPython3)
       ├─ docs/dynamo_node.py            : 치수 수동/파라미터 추출
       └─ docs/dynamo_joint_detection.py : 보·기둥 겹침 자동탐지(기하)
            └─ takeoff.runner.run(members, out_path, overlaps=...)
                 ├─ models.py  : 입력 검증 · 그룹키
                 ├─ overlap.py : 겹침 우선순위 귀속(한 번만 계산)   ← 핵심
                 ├─ calc.py    : 카테고리별 산출식 + 계산값
                 └─ excel.py   : openpyxl 수량산출서(집계/콘크리트/거푸집/수량/길이)
```

**설계 원칙**: Revit 의존 작업(요소 순회·기하)은 Dynamo 노드에, **계산·집계·겹침 귀속
로직은 순수 Python**에 둔다 → Revit 없이 테스트·디버깅 가능, VS Code에서 Claude가
로직을 직접 수정. 실패 시 노드가 `*.error.log` 를 남겨 스샷 없이 원인 파악.

## 4. 산정 규칙 (기본값, `calc.py`)

치수 단위 m. 회사/표준품셈 기준에 맞게 조정 (`docs/formwork_rules.md`).

| 카테고리 | 콘크리트 (m³) | 거푸집 (m²) |
|----------|---------------|-------------|
| 기둥 | `b×h×높이×n` | `2×(b+h)×높이×n` (4면) |
| 보 | `b×h×길이×n` | `(2h+b)×길이×n` (양측면+바닥) |
| 기초 | `B×L×H×n` | `2×(B+L)×H×n` (측면) |
| 슬래브 | `면적×두께×n` | `면적(+둘레×두께)×n` |
| 벽 | `길이×높이×두께×n` | `2×길이×높이×n` (양면) |

동일 규격 부재는 자동 그룹 집계되어 개수로 합산.

## 5. 겹침 '한 번만' 계산 — 우선순위 귀속 (핵심)

두 부재가 겹치는 구간은 **우선순위가 높은 부재 하나가 소유**(체적 그대로 포함)하고,
낮은 부재에서만 그 길이를 공제한다. **처리 순서가 아닌 정해진 우선순위**로 판정하므로
입력 순서와 무관하게 정확히 한 번만 계산된다 (중복·누락 없음).

기본 우선순위 (`overlap.DEFAULT_PRIORITY`): 기초(0) > 기둥(1) > 벽(2) > 보(3) > 슬래브(4)

- 예) 보-기둥 접합부 → **기둥이 소유**(높이 그대로), **보가 길이 공제**.
- 예) 기둥-기초 접합부 → **기초가 소유**, **기둥이 높이 공제**.
- 공제는 loser 의 선형치수(`deduct_length`/`deduct_height`)에 누적.
- 데이터 흐름: Dynamo 기하 → `overlaps=[{a,b,length}]` → `resolve_overlaps`(그룹 집계 전).

## 6. 출력 엑셀

- 시트: `집계` / `콘크리트(m³)` / `거푸집(m²)` / `부재수량(EA)` / `부재길이(m)`
- 각 시트: No·공종·부재기호·규격·층·**산출식**·수량·단위·비고 + 카테고리 소계 + 합계
- 산출식은 순값만(겹침 미표기), 공제 내역은 비고에.

## 7. 테스트 (Revit 불필요, `py -m unittest`)

- `test_calc.py` : 카테고리별 산출식·값, 겹침 공제, 오류
- `test_overlap.py` : 우선순위 귀속, 입력순서 무관, 한 번만 계산
- `test_runner.py` : 그룹 집계, 엑셀 생성·합계
- 현재 **28개 통과**.

## 8. 현재 한계 / 수동 처리

- **슬래브–보**, **벽 개구부** 겹침: 자동 공제 미지원 → 입력 치수 조정으로 처리.
- 패밀리별 파라미터 이름(`b`,`h`,`단면폭` 등)은 프로젝트에 맞게 매핑 필요.
- 거푸집 산정식은 기본 가정(접합부 일부 공제 생략) — 기준에 맞게 조정 권장.

## 9. 로드맵

1. **슬래브–보 / 개구부 공제**: `deduct_volume`·`deduct_formwork` 일반화.
2. **조인트 탐지 확장**: 기둥-기초, 벽-기둥, 슬래브-보까지 기하 자동탐지.
3. **엑셀 양식 고도화**: 표준 수량산출서 양식(병합셀·테두리·표지) 근접.
4. **실모델 검증**: Revit 2026 샘플로 파라미터 매핑·산정식 보정.
