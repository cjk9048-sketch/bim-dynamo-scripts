# 드론 360 로드뷰

DJI Avata 360 영상(.OSV)으로 상수도 설계용 로드뷰를 만들고, 관로(SHP · Civil 3D DXF)를 겹쳐 본다.
웹(NAS)으로 공유한다.

## 쓰는 법

`로드뷰_만들기.cmd` → 창:

1. **영상 고르기** (OSV 여러 개) · **간격 (m)** · 결과 폴더
2. **관로 (선택)** — SHP 면 속성표에서 **관경 항목(mm)** 고르기 (이름 항목은 선택). DXF 면 도면층 거르기.
   **평균매설깊이 (m)** = 땅 → 관 윗면.
3. **만들기** → 끝나면 **로드뷰 열기** · **NAS 올리기** (주소 복사)

다시 만들면 같은 장면 360 사진은 그대로 쓴다 (관로만 바꿀 때 몇 초). 맞춤 값(`data/calib.js`)은 안 덮는다.

명령줄:

```
python -m roadview.build 영상폴더 --out 결과폴더 --interval 5 [--pipes 관로.shp --dia-field 관경 --depth 1.2]
python -m roadview.share 결과폴더            # NAS 올리기 (이어 올리기) · --test · --new · --remove
```

## 보기 화면

- 360: 끌기 · 휠 · ←/→ · 땅 위 원을 누르면 그 촬영점으로.
- 관로: **노면** = 관경 두께의 띠 (땅 위) · **깊이** = 3D 관 (땅 − 평균매설깊이 − 반지름).
  SHP 는 Z 를 쓰지 않는다. Civil 3D 3D 폴리선(DXF)은 설계 높이를 쓴다.
- 지도: 웹 주소로 열면 OSM. 파일로 열면(file://) OSM 이 막혀서 격자만 — «지도 키»(VWorld)를 넣거나 웹 주소로.
- 맞춤: 영상마다 동 · 북 · 높이 · 방향 · 기울기.

## 하는 일

1. OSV 안 기록(djmd)에서 장면마다 GPS · 이륙점 기준 높이 · 드론 자세 · 참 북 방향을 읽는다 (`osv.py`).
2. 진행 거리 간격마다 장면을 고른다.
3. 땅 위 높이를 영상으로 잰다 — 두 장면의 «위에서 본 땅 그림»이 겹치는 높이 (`height.py`).
4. 어안 두 장을 꿰매 수평 · 격자 북 기준 360 사진으로 (`camera.py`, 렌즈 값 `rig_avata360.json`).
5. 관로를 읽어(`shp.py` · `pipes.py` · `pipeload.py`) 경로 200 m 안만 남기고, 꼭짓점마다 땅 높이를 채운다.
6. NAS 올리기는 Civil 3D 3D 웹 공유와 같은 설정 · 비밀번호(%APPDATA%\DH.Grading)를 쓴다 (`share.py`).

## 정확도 (0014 영상 · 시험 관로)

- 촬영점에서 40 m 안: 0.3~0.5 m
- 50~65 m: 1~2 m (낮은 각도라 높이 오차가 늘어남)
- 절대 위치는 드론 GPS 오차(보통 수 m)만큼 통째로 밀릴 수 있다 → «맞춤»으로 영상마다 보정.
