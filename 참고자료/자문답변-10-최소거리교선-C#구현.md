# [자문 답변 #10] 캐드 '지표면 간 최소 거리' 완벽 모방 C# 구현

> **문서 요약:** 스크린샷의 엉성한 초록색 선(Ray-marching 결과)을 버리고, 캐드 기본 기능이 도출해낸 하얀색 선(완벽한 교선)을 C#으로 똑같이 뽑아내는 모듈 코드를 제공합니다.

---

## 1. 하얀색 선(캐드 UI)과 초록색 선(C#)의 차이점

* **초록선 (Ray-marching):** 경계에서 `0.4m` 간격(marchStep)으로 점을 쏘면서 높이를 비교했습니다. 아무리 촘촘히 쏴도 점과 점 사이는 직선으로 이어지므로 둥근 지형에서는 톱니처럼 각지게 됩니다. (오차 발생)
* **하얀선 (최소 거리 도구):** 캐드 엔진이 두 TIN 표면을 이루는 **'모든 삼각형의 교차 선분'**을 수학적으로 계산하여 3D 폴리라인으로 이은 것입니다. (오차 0%)

이 하얀선의 계산을 C#에서 호출하려면, 직전 v3에서 검증해 드린 **`TinVolumeSurface` + `UserContour (0.0)`** 방식 외에는 답이 없습니다. 이 방식이 바로 하얀색 선을 만들어내는 캐드 엔진의 백엔드 로직이기 때문입니다.

## 2. 완벽 교선 추출 전용 모듈 (복붙용 코드)

기존 플러그인의 `GradingGeometry.cs` 나 `SurfaceBuilder.cs` 옆에 새로운 클래스로 추가하십시오.

```csharp
using Autodesk.AutoCAD.DatabaseServices;
using Autodesk.AutoCAD.Geometry;
using Autodesk.Civil.DatabaseServices;
using System.Collections.Generic;

namespace DH.Grading.Civil
{
    public static class ExactIntersectionFinder
    {
        /// <summary>
        /// 캐드의 '지표면 최소 거리'와 100% 동일한 완벽한 3D 교선(Daylight)을 추출합니다.
        /// </summary>
        /// <param name="groundId">원지반 TinSurface의 ObjectId</param>
        /// <param name="virtualSlopeId">오버사이즈로 생성된 가상 계단면 TinSurface의 ObjectId</param>
        /// <returns>완벽히 밀착된 교선(Daylight) 폴리곤 정점 목록</returns>
        public static List<Point3dCollection> GetExactDaylightLines(Database db, Transaction tr, ObjectId groundId, ObjectId virtualSlopeId)
        {
            var intersectionLines = new List<Point3dCollection>();

            // 1. 교선 계산을 위한 임시 토량 지표면(Volume Surface) 생성
            // 이 지표면은 도면에 일시적으로만 존재하며, Z=0인 곳이 곧 두 면의 완벽한 교차선이 됩니다.
            ObjectId volSurfId = TinVolumeSurface.Create("Temp_Calc_Surface", groundId, virtualSlopeId);
            var volSurf = (TinVolumeSurface)tr.GetObject(volSurfId, OpenMode.ForWrite);

            try
            {
                // 2. User Contour (사용자 등고선) 기능으로 Z=0 교선 뽑아내기
                SurfaceAnalysisUserContourData[] ucData = new SurfaceAnalysisUserContourData[1];
                ucData[0] = new SurfaceAnalysisUserContourData();
                ucData[0].Elevation = 0.0; // 높이차 0 = 만나는 곳
                volSurf.Analysis.SetUserContoursData(ucData);

                // 3. 엔진에 계산 명령 -> 선(Polyline/Polyline3d) 객체들 반환
                ObjectIdCollection contourIds = volSurf.ExtractUserContours();

                // 4. 선 객체들에서 좌표 긁어오기
                foreach (ObjectId id in contourIds)
                {
                    var ent = tr.GetObject(id, OpenMode.ForWrite) as Entity;
                    Point3dCollection pts = new Point3dCollection();

                    if (ent is Polyline3d poly3d)
                    {
                        foreach (ObjectId vxId in poly3d)
                        {
                            var vx = tr.GetObject(vxId, OpenMode.ForRead) as PolylineVertex3d;
                            if (vx != null) pts.Add(vx.Position);
                        }
                    }
                    else if (ent is Polyline poly2d)
                    {
                        for (int i = 0; i < poly2d.NumberOfVertices; i++)
                        {
                            pts.Add(poly2d.GetPoint3dAt(i));
                        }
                    }

                    // 쓰레기 선(노이즈) 제거 및 리스트에 담기
                    if (pts.Count >= 3)
                    {
                        intersectionLines.Add(pts);
                    }

                    // 도면에서 선 객체 즉시 삭제
                    ent?.Erase();
                }
            }
            finally
            {
                // 계산이 끝났으므로 임시 토량 지표면은 즉시 삭제
                volSurf.Erase();
            }

            return intersectionLines;
        }
    }
}
```

## 3. 메인 로직 적용 가이드 (어떻게 수정해야 하는가?)

유저님의 기존 코드를 보면, Daylight를 **"가상면 TIN을 만들기 전"**에 수식으로 예측하고 있었습니다. 이 순서를 완전히 뒤집어야 하얀색 선을 얻을 수 있습니다.

### [수정 전 (기존 로직 흐름)]
1. 계획선 오프셋으로 링 생성
2. **Ray-marching으로 Daylight 점 쏘아서 추측 (이게 초록색 선)**
3. 가상면 TIN 생성
4. 2번의 추측 선으로 TIN 클립 -> **(어긋나니까 붕 뜨고 찢어짐)**

### [수정 후 (새로운 로직 흐름)]
1. 계획선 오프셋으로 **충분히 큰(Oversize) 링 생성**. (원지반을 완전히 파고들거나 완전히 덮을 때까지 끝까지 오프셋만 합니다.)
2. 이 오버사이즈 링들로 **가상면 TIN을 먼저 무조건 생성**합니다. (클립하지 않은 상태의 무식하게 큰 지표면)
3. 위에서 제공한 `ExactIntersectionFinder.GetExactDaylightLines(...)` 에 원지반과 방금 만든 가상면을 넘겨줍니다.
4. **결과물(하얀색 선) 획득!** 이 선을 Outer Boundary로 설정하여 2번의 오버사이즈 TIN을 잘라내면, 종이 자르듯 완벽한 계단식 정지면이 완성됩니다.

이 방식은 수식(Prediction)이 아니라 형상(Topology) 간의 실제 교차(Boolean)를 수행하므로, 스크린샷에서 보신 캐드의 그 하얀 선을 100% 일치하게 뽑아냅니다.
