# [자문 요청 #5] 계단식 정지 — 단(터레이스) 끝에서 세로 빗살(comb)로 깨지는 문제

## 0. 한 줄 요약
Civil3D `TinSurface` 계단식 절·성토 정지면을 만드는데, **큰 비탈·소단 면은 매끈하지만, 단(터레이스)이 옆에서 끝나는 지점에서 세로 단차(riser)가 빗살(comb)처럼 수직 삼각형으로 깨짐.** 단을 옆에서 자연스럽게 마무리(폭 0으로 좁혀 비탈에 흡수)하거나 빗살을 없애는 방법을 묻고자 함.

---

## 1. 목표 / 환경
- **목표**: 계획 폴리곤(평지, 단일 계획고)에서 바깥으로 **5m 비탈 + 1m 소단**을 반복하는 계단식 절·성토 정지면을 자동 생성. 배수지·정수장 같은 **소규모** 부지(도로/대규모 아님). 수직 옹벽이 아니라 **매끈한 계단 정지**가 목표.
- **환경**: Civil3D 2026 / .NET 8 / NetTopologySuite 2.5. 출력은 Civil3D `TinSurface`(브레이크라인 + 정점 + Outer 경계).
- **파라미터 예**: 단높이 H=5m, 소단폭 1m, 절토구배 1:1, 성토구배 1:1(또는 1:1.5). 한 비탈의 수평길이 slopeRun = H·slope = 5m, 한 주기 period = slopeRun+소단 = 6m.

## 2. 현재 아키텍처 (Hybrid: NTS Buffer + Z-clip + 채움정점 + daylight)
입력: 계획경계 폴리곤(평면 plane, 모든 점 designZ), 원지반 `IGroundSurface`(TIN, `TryGetElevation(x,y)`).

1. **daylight 폴리곤**(절토/성토 각각): 경계에서 바깥 법선으로 ray-march. 각 방향으로 계단 프로파일(designZ ± Height(d))이 원지반과 만나는 점을 찾음 → 그 점들로 폴리곤 → `Buffer(0)`으로 꼬임(bow-tie) 정리. = "정지면이 원지반과 만나는 외곽선(toe)".
2. **단 모서리(브레이크라인)**: 계획경계를 `Buffer(d)`로 바깥 오프셋(동심 링). 단 k의 사면위 모서리 d=(k-1)·period+slopeRun, 소단바깥 d=k·period, 둘 다 Z=designZ±k·H.
   - 각 링을 **daylight 폴리곤의 1cm 인셋(Safe-Zone)** 으로 2D 클립(`ExteriorRing.Intersection(daylight.Buffer(-0.01))`) → 단이 daylight 뼈대에 1cm 전 멈춰 교차 회피.
   - 그 뒤 **3D Z-clip**: 링을 따라가며 각 점의 원지반고를 읽어, **절토는 원지반≥단고인 구간만** 살리고 경계에서 원지반==단고가 되는 점을 보간해 **pinch-out**(단이 원지반과 만나는 곳서 소멸).
3. **비탈면 채움 정점**: 단 모서리 사이 비탈을 ≈1m 간격 오프셋 링으로 채워, 각 점에 프로파일고(designZ±Height(d))를 주고 역시 Z-clip(pinch-out)해서 **정점(브레이크라인 아님)** 으로 추가. → 단끼리 사이의 비탈/단끝 빈 곳을 메워 TIN이 평평하게 잇는 것(webbing) 방지.
4. **TIN 조립**: 단 모서리=브레이크라인, daylight=**브레이크라인 + Outer 경계(파괴식)** 둘 다, 채움=정점(AddVertices). 모든 점 1mm 중복제거.

## 3. 핵심 코드 (C#, NetTopologySuite)

### 3.1 단 모서리 생성 (Buffer → 1cm SafeZone 2D클립 → 3D Z-clip)
```csharp
private static void AddClippedBenches(HybridResult result, Polygon basePoly, Plane plane, GradingParams p,
    BufferParameters bp, Geometry dayPoly, IGroundSurface ground, bool up)
{
    double slope = Math.Max(up ? p.CutSlope : p.FillSlope, p.MinSlope);
    double slopeRun = Math.Max(p.BenchHeight * slope, p.MinFaceRun);
    double period = slopeRun + p.BenchWidth;
    double zdir = up ? 1.0 : -1.0;
    double densifyStep = Math.Max(0.25, Math.Min(p.CellSize, 0.5));
    var gf = new GeometryFactory();

    Geometry safeZone = dayPoly;
    try { var inset = dayPoly.Buffer(-0.01); if (!inset.IsEmpty) safeZone = inset; } catch { }

    for (int k = 1; k <= p.MaxBenches; k++)
    {
        double zOff = zdir * k * p.BenchHeight;
        foreach (double d in new[] { (k - 1) * period + slopeRun, k * period }) // 사면 위 / 소단 바깥 모서리
        {
            if (d <= 1e-9) continue;
            Geometry g; try { g = basePoly.Buffer(d, bp); } catch { continue; }
            var pg = LargestPolygon(g); if (pg == null) continue;
            Geometry clipped; try { clipped = pg.ExteriorRing.Intersection(safeZone); } catch { continue; }
            foreach (var line in ExtractLines(clipped))
            {
                Coordinate[] coords = Densify(gf.CreateLineString(line.ToArray()), densifyStep).Coordinates;
                foreach (var seg in ClipRingByGround(coords, plane, zOff, ground, up)) // 3D Z-clip(pinch-out)
                {
                    var w = Weed(seg);
                    if (w.Count >= 2) result.BenchRings.Add(w); // 브레이크라인
                }
            }
        }
    }
}
```

### 3.2 3D Z-clip (pinch-out 핵심)
```csharp
// 절토 단: 원지반(zg) >= 단고(benchZ) 인 곳만 유효. 경계에서 zg==benchZ 되는 점을 선형보간해 단 끝점으로.
private static List<List<Point3>> ClipRingByGround(Coordinate[] coords, Plane plane, double zOff,
    IGroundSurface ground, bool up)
{
    var segments = new List<List<Point3>>(); var cur = new List<Point3>();
    bool wasInside = false, havePrev = false; double pX=0, pY=0, pDiff=0;
    foreach (var c in coords)
    {
        double benchZ = plane.At(c.X, c.Y) + zOff;
        double diff; bool inside;
        if (ground.TryGetElevation(c.X, c.Y, out double zg)) { diff = up ? zg-benchZ : benchZ-zg; inside = diff >= 0; }
        else { diff = -1; inside = false; }
        if (inside) {
            if (!wasInside && havePrev) cur.Add(InterpAtGround(pX,pY,pDiff, c.X,c.Y,diff, plane, zOff)); // 진입 소멸점
            cur.Add(new Point3(c.X, c.Y, benchZ));
        } else if (wasInside && havePrev) {
            cur.Add(InterpAtGround(pX,pY,pDiff, c.X,c.Y,diff, plane, zOff)); // 이탈 소멸점
            if (cur.Count >= 2) segments.Add(cur); cur = new List<Point3>();
        }
        wasInside = inside; havePrev = true; pX=c.X; pY=c.Y; pDiff=diff;
    }
    if (cur.Count >= 2) segments.Add(cur);
    return segments;
}
```

### 3.3 비탈면 채움 정점 (단 모서리 사이를 ≈1m 링으로 메움, 동일 Z-clip)
```csharp
private static void AddSlopeFill(..., bool up)
{
    // period/slopeRun 동일. fillStep ≈ 1m. Profile(d): 완료단수 k*H + (비탈이면 부분상승, 소단이면 +H), 단수 캡.
    for (double d = fillStep; d <= maxReach; d += fillStep)
    {
        var pg = LargestPolygon(basePoly.Buffer(d, bp));
        var clipped = pg.ExteriorRing.Intersection(safeZone); // 1cm SafeZone
        double zOff = zdir * Profile(d);
        foreach (var line in ExtractLines(clipped))
        {
            var coords = Densify(line, densifyStep);
            foreach (var seg in ClipRingByGround(coords, plane, zOff, ground, up))
                result.FillVertices.AddRange(seg); // 정점(AddVertices)
        }
    }
}
```

### 3.4 TIN 조립
```csharp
// 1) 단 모서리 = 브레이크라인
```

## 4. 지금까지 해결한 것 (이전 자문 #1~#4 반영, 모두 성공)
- **강제채움(webbing)**: 0.1m 인셋 폐기 → 3D Z-clip(원지반서 pinch-out)으로 단이 허공에 안 뜨게. (자문 #3)
- **각짐**: daylight를 Breakline+Outer 둘 다로 복원 + 계획면 경계를 0.5m로 촘촘히. (자문 #4)
- **교차오류**: 단을 daylight 1cm SafeZone 안쪽까지만 → 교차 0(1cm는 TIN이 매끄럽게 융합).
- **긴 부채꼴(fan) 삼각형**: daylight선을 채움 점 밀도(0.5m)에 맞춰 densify.
- **끝단 톱니(1차)**: 채움 링도 단처럼 pinch-out 시켜 끝점이 daylight선에 나란히.

## 5. 남은 문제 (이번 자문 대상)
큰 비탈·소단 면은 매끈한데, **단(터레이스)이 옆에서 끝나는 지점**(원지반이 그 단의 높이 밑으로 내려가 단이 소멸하는 곳)에서 **세로 단차가 빗살(comb)처럼 수직 삼각형으로 쫙쫙 깨짐.**

### 추정 원인
- 단(예 z=110)은 **상수높이 브레이크라인**. 원지반이 110 이상인 곳만 존재하고 옆에서 pinch-out(z=110, 원지반==110)로 끝남.
- 그 끝점(z=110) **바로 옆**에는 더 낮은 원지반/채움 점(예 z=106~109)이 XY로는 가깝게 있음. → TIN(Delaunay)이 높은 단 끝점과 낮은 옆 점들 사이를 **거의 수직인 가느다란 삼각형(빗살)** 으로 분할.
- 즉 단의 **옆면 마무리(end-cap/return)** 가 정의돼 있지 않아, 상수높이 단 브레이크라인 끝 ↔ 낮은 주변 점의 Z 점프를 TIN이 수직 슬리버로 메움.
- 1m 폭 소단의 끝(평평한 띠가 옆에서 끊기는 곳)도 같은 원리로 수직 단차 빗살이 생김.

## 6. 질문
1. 계단식 정지에서 **단(터레이스)이 옆에서 끝나는 지점**을, 수직 단차 빗살 없이 **자연스럽게 마무리**하려면 어떻게 모델링해야 하나? (예: 단 끝에서 소단폭을 0으로 점진적으로 좁혀 비탈에 흡수? 단 끝에 명시적 "return slope" 브레이크라인 추가? 다른 위상?)
2. 상수높이 단 브레이크라인 + 원지반 pinch-out 조합이 근본적으로 이 빗살을 유발한다면, **단 모서리를 constant-Z 브레이크라인으로 두는 것** 자체를 바꿔야 하나? (예: 단 끝 근처에서는 브레이크라인을 빼고 정점만? daylight도 끝에서는 다르게?)
3. NTS Buffer 동심 오프셋 + Civil3D TIN 조합에서 이 "단 끝 빗살"을 없애는 **구체적 기법**(코드 수준)이 있는지?
4. 혹시 접근 자체(constant-Z 단 + 채움정점 + daylight 트림)가 단 끝 처리에 부적합하고, **다른 표면 구성**(예: 순수 방사 단면 점군, 또는 단 끝마다 부채꼴 warp surface)이 더 나은지?
