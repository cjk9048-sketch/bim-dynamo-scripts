# [자문 답변 #6] 단끝 잔여 탭 및 미세 톱니 완벽 해결 가이드

> **문서 요약:** 테이퍼링의 부작용(내부 탭 발생)과 2D 독립 링의 한계(끝점 불일치)를 진단하고, 이를 대체할 **'위상 용접(Topology Welding)'** 기법 및 **'Daylight Outer 전용화'**를 통해 매끈한 종단(End-Cap) 마무리를 달성하는 방법을 제시합니다.

## 1. 현재 문제 진단 및 질문에 대한 답변

### Q1. Toe 끝점과 Top 끝점을 정확히 한 점으로 스냅/공유시키려면?
* **원인:** 자문 #5에서 제안한 수식(`benchWidth*(1-dist)`)은 방향성(Normal)을 수학적으로 추정할 뿐, 두 개의 독립된 NTS Buffer 링(Top 링과 Toe 링)의 정점 배열 개수와 위치가 다르기 때문에 **XY 좌표가 절대 일치할 수 없습니다.**
* **해결:** 테이퍼링 수식을 버리십시오. 대신 생성된 3D Line(`List<Point3>`) 데이터 레벨에서 **Toe의 끝점을 Top의 끝점으로 강제 덮어쓰기(Overwrite)하여 '용접(Weld)'**해야 합니다.

### Q2. 높이 탭 없이 비탈로 흡수하려면 무엇이 더 필요한가? (내부 오류 원인)
* **원인:** 테이퍼링이 '절/성토 전환부(내부)'와 '실제 원지반 소멸점(외부)'을 구분하지 못하고 무조건 끝점을 당겼기 때문에 내부 탭이 발생했습니다. 
* **해결:** 단 모서리를 `constant-Z`로 두는 것은 맞습니다. 하지만 끝점을 당기는 처리는 오직 **"단이 원지반과 만나는(Pinch-out) 진짜 끝단"**에서만 수행해야 합니다.

### Q3. Daylight를 Outer 트림 전용으로 바꿔도 되나? (끝단 톱니의 원인)
* **강력히 권장합니다.** 현재 톱니(Jagged Toe)가 생기는 이유는 1) 촘촘한 채움 정점(Fill Vertices) 2) Pinch-out된 단 끝점 3) Daylight 브레이크라인... 이 세 가지 데이터가 XY 평면상에서 미세하게 엇갈리면서 삼각망이 엉키기 때문입니다.
* **해결:** 이미 채움 정점(`AddVertices`)이 Toe 영역의 Z값을 훌륭하게 잡아주고 있습니다. **Daylight는 브레이크라인에서 빼고 `Outer Boundary`로만 적용**하십시오. 가위 역할만 하게 두면 톱니가 즉시 사라집니다.

### Q4. 더 단순·견고한 표준 기법이 있는지?
* Civil 3D의 Corridor나 Grading은 원래 이런 경우 방사형(Radial) 단면 뼈대를 세우고 코너에서 부채꼴(Bow-tie)을 만듭니다. 하지만 현재 NTS 기반의 동심 링(Concentric Rings) 아키텍처를 여기까지 끌고 오셨다면, 이를 버리지 마시고 **'명시적 End-Cap(끝단 닫음)'** 브레이크라인을 생성하는 것이 가장 빠르고 견고한 해결책입니다.

## 2. 해결 코드: Topology Welding (강제 용접 기법)

수학적 테이퍼링 대신, **Toe Arc의 양쪽 끝점을 Top Arc의 끝점에 강제로 스냅(Snap)** 시켜 폭을 0으로 물리적으로 닫아버리는(End-Cap) 방법입니다.

### [수정 로직 1] 기존 `TaperArcEnds` 삭제 및 `WeldBenchEnds` 적용
`AddClippedBenches` 함수 루프 내에서, 하나의 단(Level $k$)에 대해 Top Arc와 Toe Arc를 구한 뒤 아래 헬퍼 함수를 호출하여 끝점을 하나로 묶습니다.

```csharp
// Top(사면 위) Arc들과 Toe(소단 바깥) Arc들을 입력받아,
// Toe Arc의 끝점을 가장 가까운 Top Arc의 끝점에 강제로 스냅(용접)합니다.
private static void WeldBenchEnds(
    List<List<Point3>> topArcs, 
    List<List<Point3>> toeArcs, 
    double snapTolerance = 5.0) // 끝점이 5m 이내일 때만 진짜 끝단으로 간주(내부 탭 방지)
{
    foreach (var toeArc in toeArcs)
    {
        if (toeArc.Count < 2) continue;

        Point3 toeStart = toeArc[0];
        Point3 toeEnd = toeArc[toeArc.Count - 1];

        // 1. Toe 시작점 용접
        Point3? closestTopStart = FindClosestEndPoint(toeStart, topArcs, snapTolerance);
        if (closestTopStart.HasValue)
        {
            // Toe의 시작점 XY를 Top의 시작점 XY로 강제 이동 (Z는 유지)
            toeArc[0] = new Point3(closestTopStart.Value.X, closestTopStart.Value.Y, toeStart.Z);
            
            // 극단적인 꺾임을 막기 위해 2번째 점도 살짝 보간 (선택 사항)
            if (toeArc.Count > 2) {
                toeArc[1] = Point3.Interpolate(toeArc[0], toeArc[2], 0.5);
            }
        }

        // 2. Toe 끝점 용접
        Point3? closestTopEnd = FindClosestEndPoint(toeEnd, topArcs, snapTolerance);
        if (closestTopEnd.HasValue)
        {
            // Toe의 끝점 XY를 Top의 끝점 XY로 강제 이동 (Z는 유지)
            toeArc[toeArc.Count - 1] = new Point3(closestTopEnd.Value.X, closestTopEnd.Value.Y, toeEnd.Z);
            
            if (toeArc.Count > 2) {
                toeArc[toeArc.Count - 2] = Point3.Interpolate(toeArc[toeArc.Count - 1], toeArc[toeArc.Count - 3], 0.5);
            }
        }
    }
}

// 가장 가까운 Top Arc의 끝점(Start 또는 End)을 찾는 헬퍼 함수
private static Point3? FindClosestEndPoint(Point3 target, List<List<Point3>> arcs, double tolerance)
{
    Point3? closest = null;
    double minDist = tolerance * tolerance; // 비교를 위해 제곱값 사용

    foreach (var arc in arcs)
    {
        if (arc.Count < 1) continue;

        Point3 startPt = arc[0];
        Point3 endPt = arc[arc.Count - 1];

        double distStart = Dist2DSq(target, startPt);
        if (distStart < minDist) { minDist = distStart; closest = startPt; }

        double distEnd = Dist2DSq(target, endPt);
        if (distEnd < minDist) { minDist = distEnd; closest = endPt; }
    }

    return closest;
}

private static double Dist2DSq(Point3 p1, Point3 p2)
{
    return (p1.X - p2.X) * (p1.X - p2.X) + (p1.Y - p2.Y) * (p1.Y - p2.Y);
}
```

## 3. 작동 원리 및 결과 예측

1. **내부 오류(탭) 방지:** `WeldBenchEnds`의 `snapTolerance(5m)` 덕분에, 절/성토 전환부 내부에서 멀리 떨어진 채로 끊기는 단들은 용접되지 않고 그대로 유지됩니다. 진짜로 원지반과 만나 폭이 좁아지는 맨 끝단에서만 스냅이 발생합니다.
2. **미세 탭 소거:** Toe의 끝 XY가 Top의 끝 XY와 수학적으로 **100.000% 완벽하게 일치**하게 되므로, $Z=110m$와 $Z=105m$ 사이를 잇는 얇은 칼날 삼각형(Sliver)이 생길 면적(Area) 자체가 0이 되어 사라집니다.
3. **매끈한 맨 끝단(Toe):** 삼각망 엔진은 촘촘한 정점들을 이용해 부드러운 사면을 만들고, 마지막에 `Outer` 가위가 잘라내므로 미세한 톱니나 들쭉날쭉한 지그재그 선이 매끈한 곡선으로 바뀝니다.
