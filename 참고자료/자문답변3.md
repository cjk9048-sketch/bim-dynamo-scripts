# [자문 답변 #3] 0.1m 인셋 부작용(강제 채움) 해결 및 3D Z-Clipping 기법

> **문서 요약:** 0.1m 인셋(Inset)으로 인해 발생하는 단 끝부분의 '강제 채움(Webbing)' 현상을 분석하고, 2D 클리핑 대신 원지반 고도를 활용하여 단(Bench)을 자연스럽게 지형에 소멸시키는 **3D Z-Clipping** 아키텍처를 적용합니다.

## 1. 스크린샷 분석: "강제 채움"은 왜 일어났는가?

스크린샷의 각진 덩어리(Webbing/Facet)는 0.1m 인셋이라는 '공백(Gap)'을 TIN 엔진이 강제로 이어붙이면서 생긴 현상입니다.

1. **0.1m의 틈새:** `Intersection` 시 Daylight 폴리곤을 0.1m 줄였기 때문에, 단 모서리(Breakline)가 Daylight 경계선에 닿지 못하고 **0.1m 앞에서 공중에 뜬 채로 끊어집니다.**
2. **TIN 엔진의 억지 연결:** 델로네(Delaunay) 알고리즘은 이렇게 끊긴 단의 끝점(Z=설계단고)과, 그 앞에 있는 Daylight 경계선의 점(Z=원지반고)을 하나로 연결해 거대한 삼각형을 만들어 버립니다.
3. 이 삼각형이 경사면을 덮어버리면서 마치 종이접기가 잘못된 것 같은 강제 채움 면(Facet)이 발생한 것입니다.

**왜 0.1m 인셋을 쓰셨나요?** 인셋 없이 2D Daylight 폴리곤으로만 자르면 '수직 벽(Wall)'이 생기기 때문이었을 것입니다. 2D 평면에서 교차점을 찾다 보니, 단이 끊기는 지점의 원지반 높이가 단의 높이와 정확히 일치하지 않아 Z값이 튀는 현상이 있었기 때문입니다.

## 2. 궁극의 해결책: 3D 고도 기반 클리핑 (Z-Clipping)

이제 2D Daylight 폴리곤으로 단(Bench) 링을 자르는 방식을 **완전히 버리셔야 합니다.**
대신, 벤치 링의 각 점 위치에서 '원지반의 실제 Z값'을 읽어와서 단을 잘라내는 **Z-Clipping**을 적용합니다.

### [작동 원리]

1. NTS `Buffer`로 만든 2D 단 모서리 링(예: Z = 35m)의 둘레를 따라갑니다.
2. 각 XY 좌표에서 원지반의 고도(Z_ground)를 확인합니다.
3. **절토 단(Cut Bench)인 경우:** 산을 깎아서 만든 단이므로, 원지반 고도가 단 고도보다 높거나 같아야(Z_ground >= 35m) 땅속에 존재하는 유효한 단입니다. 만약 원지반 고도가 35m보다 낮아진다면, 단이 허공으로 튀어나온 것이므로 선을 끊어버립니다.
4. **성토 단(Fill Bench)인 경우:** 흙을 쌓아 만든 단이므로, Z_ground <= 35m 인 구간에서만 선을 살립니다.
5. **[핵심] 소멸점(Pinch-out) 보간:** 선이 유효 구간에서 무효 구간으로 넘어가는 찰나의 순간! 그 선분 사이에서 선형 보간을 통해 **정확히 Z_ground == 35m가 되는 XY 좌표**를 찾아내어 단의 끝점으로 삼습니다.

이 방식을 쓰면, 단 모서리 선이 Daylight 경계면 근처에서 원지반과 높이가 완벽히 일치하는 지점에서 스스로 **소멸(Pinch-out)** 합니다. 0.1m 인셋 같은 꼼수가 필요 없고, 끝점의 X, Y, Z가 원지반과 100% 물려 들어가므로 수직 벽이나 강제 채움이 원천 차단됩니다.

## 3. 핵심 구현 코드 (C#)

기존 클리핑 로직(`validTopBench2D = topBenchRing2D.Intersection(daylightPolygon);`)을 제거하고 아래의 헬퍼 메서드로 대체합니다.

```csharp
using NTSGeo = NetTopologySuite.Geometries;
using Autodesk.AutoCAD.Geometry;
using CivilDB = Autodesk.Civil.DatabaseServices;
using System.Collections.Generic;

// NTS 2D 링을 원지반 고도 기준으로 3D 클리핑하는 헬퍼 함수
public List<Point3dCollection> ClipBenchByElevation(
    NTSGeo.Geometry benchRing2D, 
    CivilDB.TinSurface groundSurface, 
    double benchZ, 
    bool isCut)
{
    List<Point3dCollection> validBreaklines = new List<Point3dCollection>();

    // NTS Geometry에서 좌표 배열 추출 (LineString/Polygon의 외곽선)
    NTSGeo.Coordinate[] coords = benchRing2D.Coordinates;
    if (coords.Length < 2) return validBreaklines;

    Point3dCollection currentLine = new Point3dCollection();
    bool wasInside = false;
    NTSGeo.Coordinate prevCoord = null;
    double prevZg = 0;

    for (int i = 0; i < coords.Length; i++)
    {
        NTSGeo.Coordinate coord = coords[i];
        double zg = 0;
        try 
        {
            zg = groundSurface.FindElevationAtXY(coord.X, coord.Y);
        }
        catch 
        {
            // 원지반 바운더리를 벗어난 경우 무효 처리
            zg = isCut ? double.MinValue : double.MaxValue; 
        }

        // 절토는 땅이 단보다 높아야 유효, 성토는 땅이 단보다 낮아야 유효
        bool isInside = isCut ? (zg >= benchZ) : (zg <= benchZ);

        if (isInside)
        {
            if (!wasInside && prevCoord != null)
            {
                // [진입점] 허공에서 땅 속으로 들어갈 때 -> 정확한 Z=benchZ 교차점 보간
                Point3d entryPt = InterpolateZeroPoint(prevCoord, coord, prevZg, zg, benchZ);
                currentLine.Add(entryPt);
            }
            currentLine.Add(new Point3d(coord.X, coord.Y, benchZ));
        }
        else
        {
            if (wasInside && prevCoord != null)
            {
                // [이탈점] 땅 속에서 허공으로 튀어나갈 때 -> 정확한 Z=benchZ 교차점 보간
                Point3d exitPt = InterpolateZeroPoint(prevCoord, coord, prevZg, zg, benchZ);
                currentLine.Add(exitPt);
                
                // 선이 끊겼으므로 브레이크라인 배열에 담고 새로 시작
                if (currentLine.Count > 1) validBreaklines.Add(currentLine);
                currentLine = new Point3dCollection();
            }
        }
        
        wasInside = isInside;
        prevCoord = coord;
        prevZg = zg;
    }
    
    if (currentLine.Count > 1) validBreaklines.Add(currentLine);
    return validBreaklines;
}

// 두 점 사이에서 목표 고도(targetZ)를 갖는 XY 좌표를 선형 보간하는 함수
private Point3d InterpolateZeroPoint(NTSGeo.Coordinate c1, NTSGeo.Coordinate c2, double z1, double z2, double targetZ)
{
    // Z값 차이에 따른 비율(t) 계산
    double t = (targetZ - z1) / (z2 - z1);
    if (t < 0) t = 0; 
    if (t > 1) t = 1; // 오차 방지

    double x = c1.X + (c2.X - c1.X) * t;
    double y = c1.Y + (c2.Y - c1.Y) * t;
    
    return new Point3d(x, y, targetZ);
}
```

### [메인 로직 교체 방법]

이전 문서의 루프 내부를 다음과 같이 바꿉니다. 0.1m 인셋이나 `Intersection`이 완전히 사라집니다.

```csharp
// --- [사면 위 모서리 (Top of Slope)] ---
currentOffset += p.BenchHeight * p.CutSlope;
currentZ += p.BenchHeight * dirZ;

// 1. NTS 2D 링 생성 (꼬임 제거용)
NTSGeo.Geometry topBenchRing2D = basePolygon.Buffer(currentOffset);

// 2. [변경됨] 3D 원지반 고도 기반으로 클리핑! (절토/성토 판별 변수 isCut 전달)
bool isCut = (dirZ == 1);
var validBreaklineLines = ClipBenchByElevation(topBenchRing2D, groundSurface, currentZ, isCut);

// 3. 필터링된 깨끗한 3D 선들을 브레이크라인으로 삽입
foreach (var line in validBreaklineLines)
{
    tin.BreaklinesDefinition.AddStandardBreakline(line, 1.0, 1.0, 0.05, 0.0);
}
```

## 4. 기대 효과 (최종 완성)

이 코드를 적용하면 2D에서 자를 때 발생하던 **'XY 위치와 Z 고도의 불일치'가 수학적으로 완벽하게 소거**됩니다.

1. 0.1m 인셋으로 인해 델로네 엔진이 억지로 채워넣던 삼각망(강제 채움, Webbing)이 사라집니다.
2. 단의 모서리 선이 진행하다가 원지반과 맞닿는 그 좌표에서 완벽하게 점이 찍히며 선이 종료됩니다.
3. 이 종료점의 3D 좌표는 Daylight 경계선의 3D 좌표와 완벽히 일치하므로, 브레이크라인 교차 오류 없이 지형이 종이접기처럼 깔끔하게 합쳐집니다!
