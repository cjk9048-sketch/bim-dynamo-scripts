about=GIS 설계를 위한 5단계 데이터 통합 로드 플러그인입니다 (일반판 — 계획시설 단계 제외).
    [지형 내보내기] 3단계 '지형 내보내기' 탭에서 작업 범위의 등고선을 DXF(CAD 지표면용)·SHP(GIS용)로, DEM을 GeoTIFF로 저장합니다. 등고선은 원본 5m 간격 그대로 나갑니다. 좌표계 EPSG:5186. 부지정지·사면 검토에는 등고선을, 광역 검토에는 DEM을 사용하세요.
    1단계: 작업환경 설정 (CRS + 저장형식 선택)
    2단계: 범위 설정 (사각형/다각형 그리기, 행정구역 선택, 기존레이어)
    3단계: 서버 데이터 로드 (자동 그룹화 + QML 스타일 적용)
    4단계: 로컬 데이터 로드 (드래그앤드롭 + 폴더 자동 그룹화)
    5단계: 조판생성 (A3 가로 레이아웃, 지도+제목+방위기호+축적바+범례)

changelog=
    1.3.7 - 지형 내보내기 화면 정리 (기능 변화 없음).
        · 용도를 먼저 나눴습니다 — 01 등고선(부지정지·사면 검토용, 권장) / 02 DEM(광역 검토용). 형식(DXF·SHP)은 01 안에서 고릅니다. 형식 버튼에 쓰임새를 함께 적었습니다.
        · 내보낸 뒤 결과·저장 경로와 '폴더 열기' 버튼이 나옵니다.
        · 카드 안의 설명 글씨마다 테두리가 생겨 전부 '입력칸'처럼 보였던 것을 고쳤습니다(스타일 적용 범위가 자식 위젯까지 번지던 문제).
        · 등고선은 원본 5m 간격 그대로 나갑니다.
    1.3.6 - 등고선 SHP 내보내기 추가 + 내보내기 카드 재구성: 등고선은 [DXF (CAD 지표면용)]·[SHP (GIS용)] 두 형식, DEM 은 [GeoTIFF] 로 묶어 어느 것이 무슨 용도인지 화면에서 바로 보이게 했습니다. SHP 은 표고를 Z 좌표와 elev 속성 양쪽에 저장하고 좌표계(.prj)·인코딩(.cpg)이 함께 나가며, 이진 형식이라 원본 정점 그대로도 빠릅니다(5km 기준 SHP 1.5초 / DXF 7.4초).
    1.3.5 - 지형 내보내기 카드 줄 간격 정리: 설명 3줄이 붙어 답답하던 것을 라벨 분리 + 간격으로 풀었습니다(Qt 스타일시트는 line-height 를 지원하지 않아 한 라벨의 줄바꿈으로는 간격을 줄 수 없습니다). 기능 변화 없음.
    1.3.4 - '3. 서버 로드' 단계를 하위 탭 2개로 분리: [데이터 로드] / [지형 내보내기]. 지형 내보내기가 화면 맨 아래에 있어 스크롤해야 보이던 것을 탭 전환으로 바로 접근하게 했습니다. 위자드 단계 구성과 기능은 그대로입니다.
    1.3.3 - 등고선 DXF 내보내기 속도 개선: 선 형상을 1m 허용오차로 정리해 내보냅니다(원본 수치지형도 1:5,000 의 도면 정밀도 안쪽이라 형상 손실이 없습니다). 5km 범위 기준 약 22초→8초, 파일 13.2MB→3.4MB. 화면에 쓰지도 않는 정점 수를 세느라 DB를 한 번 더 전수 조회하던 것도 제거했습니다.
    1.3.2 - 지형 내보내기에 DEM 추가: 작업 범위의 DEM을 GeoTIFF로 저장할 수 있습니다. 좌표계(EPSG:5186)가 파일에 기록되고 원본 90m 격자에 정렬되어 표고가 재보간되지 않습니다. ⚠ 90m 격자는 배수지·가압장 부지(30~80m)보다 커서 지표면이 평면으로 만들어집니다 — 광역 검토·개략 계획용으로만 쓰고, 부지정지·사면 검토에는 '등고선'을 사용하세요.
    1.3.1 - 지형 내보내기 추가: 작업 범위의 등고선을 3D DXF 파일로 저장할 수 있습니다(Civil 3D 등 CAD에서 지표면 생성용). 표고가 Z 좌표에 들어가고, 주곡선(CONTOUR_5M)과 계곡선(CONTOUR_INDEX_25M)이 도면 레이어로 분리되어 계곡선을 브레이크라인으로 쓸 수 있습니다. 등고선 도형을 작업 범위로 잘라내므로 범위 밖 자료가 딸려 나가지 않습니다. 파일의 좌표계는 EPSG:5186이며, CAD 도면 좌표계를 같게 맞춰야 위치가 맞습니다.
    1.3.0 - 하천 레이어 로딩 속도 대폭 개선: '실폭하천'에 하천명을 붙이는 과정(하천중심선과의 공간조인)이 하천중심선을 한 번 더 불러오고 공간 인덱스 없이 대조해 수십 초씩 걸리던 문제 해결. 이제 함께 로드된 하천중심선을 재사용하고 메모리 공간 인덱스로 조인하여 크게 빨라짐. 참고: 실폭하천의 하천명은 '하천중심선'을 함께 로드했을 때만 표시됩니다(단독 로드 시 이름 부여는 생략).
    1.2.0 - 작업 범위 밖 데이터 누수 수정: 모든 레이어를 DB에서 작업 범위 폴리곤과 실제로 겹치는 부분만 가져오도록 변경(개발사업·산업단지 등이 인접 시군구 것까지 통째로 들어오던 문제 해결). 대용량 레이어(건물통합정보·토지소유정보 등)는 서버에서 미리 추려 더 빠르게 로드됨.
    1.1.0 - 행정경계 법정 읍면동·리 추가 (법정/행정 경계 분리). 행정경계_법정리는 선택한 행정구역과 겹치는 법정리만, 행정경계_법정읍면동은 신규 레이어.
    1.0.0 - 초기 릴리즈
