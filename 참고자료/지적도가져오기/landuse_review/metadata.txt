QGIS 3.40.12 실환경에서 위성·지적 배경 위 렌더 확인. (2) [배경지도 상시 패널] 위자드 상단에 위성사진·수치지형도·지적도 배경을 켜고 투명도를 조절하는 바를 신설. 작업 시작 시 배경을 깔면 위치를 눈으로 확인할 수 있어, 용지경계 좌표계를 잘못 지정하면 엉뚱한 곳에 떨어지는 것이 바로 보인다(위성/수치지형은 V-World, 지적은 현재 화면 범위 DB 조회). (3) [용지경계 좌표계 추천] 좌표계 정보가 없는 CAD(DXF) 파일을 불러올 때, 선택필지의 실제 위치와 겹치는 좌표계를 자동 추천·적용한다. 좌표 숫자만으로는 좌표계를 가릴 수 없어(여러 원점이 false easting 200,000을 공유) 필지 위치를 기준으로 판별하며, 배경지도로 위치를 재확인하도록 안내한다(예: 사천은 중부원점 5186이 아니라 동부원점 5187 — 5186으로 지정하면 서해안으로 어긋나 편입 0%로 조용히 오답). 검증: QGIS 3.40.12 실환경 — 실 필지(사천 월성리·산 필지) 조회→편입 산출→삽도 렌더, 배경 3종 로드·투명도, 좌표계 추천(원본 DXF→5187·재투영본→5186), 배경 바 위젯 end-to-end.
    v1.3.2 (외부검토[Codex] 결함 수정 — 편입 계산 정확도·데이터 보호, 기능 추가 없음): (1) [F1 편입면적 스케일 정규화] 편입률의 분자(편입면적)는 지적도 도형에서 잰 값인데 분모(공부면적)는 토지대장 면적이라 두 자(尺)가 섞여, 도형면적>대장면적인 필지는 부분 편입이 100%로 인쇄되던 오류 수정(어상천면 645-1이 그 경우: 도형 4,670.7>대장 4,669.5). 편입 비율을 도형 기준(교차도형면적/필지도형면적)으로 구해 완전편입=정확히 100%·부분편입은 면적차와 무관하게 정확하게 하고, 표시 편입면적은 그 비율을 대장면적에 적용해 환산(모든 표시값이 대장 스케일로 일관). (2) [F6 공부면적 방어] 토지대장 면적(a22)이 0·NULL·nan·음수인 행이 실제로 존재 — 0/NULL을 falsy로 흘려 조용히 도형면적으로 폴백하거나 nan/음수가 검토서에 새어나가던 것을 isfinite·양수 게이트로 명시 판정하고 폴백 시 출처를 기록. (3) [F2 레이어 데이터 보호] '편입구역'·'선택필지'·'용지경계'를 이름만으로 지워 사용자가 만든 동명 레이어까지 삭제되던 위험을, 플러그인 소유 마커가 달린 레이어만 지우도록 변경. (4) [F3 게이트] 좌표계 오지정(coord_mismatch)인데도 다음 단계로 통과되던 것을 산출 성격(ok/no_inclusion)으로 판정. (5) [F4 재산출 강제] 필지·경계를 바꾼 뒤 재산출 없이 4단계로 가면 현재 필지에 과거 경계의 편입값이 섞이던 것을, 변경 시 편입 산출을 무효화해 재산출을 요구. (6) [F5 폴백 표시] 소유구분·공부면적(al_d160) 조회 실패 시 공부면적이 조용히 도형면적으로 대체되던 것을 경고하고, 도형면적으로 대체된 필지 수를 산출 결과에 표시. (7) [R5/R6] 필지 조회 가속 경로에도 statement_timeout을 둘러 경계 도형 품질 문제 시 UI 멈춤 방지. (8) [F7] README 구조표의 'ST_Intersection 서버측' 오기 정정(실제는 QGIS 클라이언트 교차). (9) CAD(DXF) 용지경계가 도로중심선·문자·원과 섞이거나 닫힘 플래그가 없어 폴리곤화 실패할 때의 안내문 개선. 검증: 헤드리스 파이썬으로 편입 스케일 합성 케이스(도형>대장/도형<대장/완전편입)·공부면적 방어 6케이스 통과. ⚠ UI·QGIS 3.40.12 실환경 동작은 사람 검증 대기(GiST 우회 전국 일반화도 미확인 — 대전리 한 곳 표본).
