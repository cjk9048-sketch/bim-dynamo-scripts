# resources/templates/ — HWPX 검토서 빈 양식

용지편입검토서 **빈 양식 템플릿** `pyeonib_report.hwpx` 가 이 폴더에 있다(✅ 포함됨).
파일이 있으면 `report_exporter` 가 사내 `gis_cn` 검증 hwpx 엔진으로 **양식을 그대로 채워**
출력하고, 없으면 동봉 python-hwpx 로 기본 초안을 만든다(하이브리드).

> 한컴오피스/COM 불필요(순수 Python lxml).

## 현재 템플릿 출처 (2026-07-08)

도로부 공식 양식 **문서B `편입여부검토(어상천면 대전리 645-1,645-6).hwpx`** 를 골든 소스로,
빈 양식으로 변환해 생성했다(빌드 스크립트: `scripts/build_pyeonib_template.py`):

- 제목표 → `meta.project_name` 누름틀 (과업명이 제목이 됨)
- 편입면적표 → 데이터 1행(프로토타입)에 `pyeonib.*` 6셀필드, 렌더러가 필지 수만큼 복제
- 삽도 슬롯 → `BinData/image2.png` 플레이스홀더(엔진이 삽도 PNG 로 바이트 교체) / 상단 레터헤드 `image1.jpg` 보존
- 누름틀 마크업 = gis_cn 검증 템플릿(`예시_빈템플릿_cn_report.hwpx`)과 동일 구조 → 한글 호환

⚠ **QGIS 3.40.12 + 한컴오피스 실개봉 검증은 대기**(엔진 자체검증·lxml well-formed·행 복제/삽도 교체는
자동 통과 확인). 실개봉 후 미세 서식(테두리·열폭)만 한글에서 최종 손질 → 결재.
도로부 **다른 공식 양식(G1)** 입수 시 같은 스크립트로 `pyeonib_report.hwpx` 교체.

## 빈 양식 제작 규칙 (한글에서)

도로부 실제 `편입여부검토(대전리 645-1,645-6).hwp` 본문 구조(① 용지편입현황 삽도
② 편입면적표)를 그대로 **빈 서식**으로 만든다(숫자·결과값은 비움).

### 1) 메타 누름틀 (입력 → 필드 → 누름틀, 이름에 아래 ID 기재)

| 누름틀 이름 | 내용 |
|---|---|
| `meta.project_name` | 과업명 |
| `meta.site_name` | 사업지구 |
| `meta.author` | 작성자 |
| `meta.organization` | 기관명(도화엔지니어링 기술개발연구원) |
| `meta.analysis_date` | 작성일(YYYY-MM-DD) |

### 2) 편입면적표 — 데이터 행은 **1행만** (렌더러가 필지 수만큼 복제)

표를 만들고 데이터 행 1줄의 각 셀에 **셀 필드**(입력 → 필드 → 누름틀)를 넣는다.
셀 필드 이름은 모두 `pyeonib.` prefix:

| 열 | 셀 필드 이름 | 값 |
|---|---|---|
| 지번 | `pyeonib.jibun` | 대전리 645-1 |
| 지목 | `pyeonib.jimok` | 전 |
| 소유자 | `pyeonib.owner` | (설계자 수동 입력값) |
| 공부면적 | `pyeonib.book_area` | 4,669.5 |
| 편입면적 | `pyeonib.enc_area` | 2,711.6 (미편입이면 "-") |
| 편입률 | `pyeonib.enc_ratio` | 58.1% (미편입이면 "-") |

### 3) 삽도 위치 — **더미 이미지 1개**를 넣어 둔다

용지편입현황 삽도 자리에 아무 PNG(예: 빈 사각형)나 **이미지 1개**를 삽입해 둔다.
플러그인이 그 이미지의 바이트만 실제 삽도 PNG 로 교체한다(한글이 등록한 구조를 재사용
→ 버전·구조에 견고). 이미지가 없으면 삽도는 생략되고 표/메타만 채워진다.
