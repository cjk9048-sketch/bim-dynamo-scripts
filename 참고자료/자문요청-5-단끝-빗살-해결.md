# [자문 답변 #5] 단(터레이스) 끝부분 세로 빗살 깨짐 현상 해결 원리 및 기법

> **문서 요약:** 상수 고도 단 브레이크라인의 끝점과 주변 낮은 채움 정점 사이의 고도 격차로 인해 발생하는 수직 빗살(Comb/Sliver) 삼각형의 원인을 진단하고, 단의 끝부분을 부드럽게 오므려 비탈면으로 흡수시키는 **3D 단 끝단 테이퍼링(End Tapering)** 구현 코드를 제시합니다.

---

## 1. 근본 원인 진단: 왜 세로 빗살(Comb)이 생기는가?

현재 적용하신 **3D Z-Clipping**은 훌륭하지만, 단 모서리선(가로선) 입장에서만 끊어짐을 처리했기 때문에 발생한 기하학적 모순입니다.

1. **상수 고도 브레이크라인의 급격한 단절:** 사면 위 모서리와 소단 바깥 모서리는 일정한 설계고($Z=110m$)를 가진 강력한 브레이크라인입니다. 이 선이 원지반과 만나 `Pinch-out`되어 뚝 끊기는 순간, 그 끝점은 고도 $110m$에 고정됩니다.
2. **소단 폭(1m)의 고도 점프:** 소단 바깥 모서리가 끊기는 점 바로 옆(1m 안쪽)에는 사면 위 모서리의 끝점이나 더 낮은 채움 정점들($Z=105m\sim109m$)이 평면(XY) 상으로 매우 가깝게 붙어 있습니다.
3. **수직 빗살 발생:** 1m 폭을 가진 소단 평면 띠가 옆에서 마무리선 없이 뚝 끊기다 보니, TIN 엔진은 **[높은 단 끝점(110m)]**과 **[바로 옆에 붙어 있는 낮은 정점들(105m)]**을 무차별적으로 엮어 수직에 가까운 칼날 모양의 칼라(Sliver) 삼각형들을 채워 넣게 됩니다. 이것이 스크린샷에 보이는 세로 빗살의 정체입니다.

## 2. 해결책: 3D 단 끝단 테이퍼링 (End-Cap Tapering)

이를 해결하려면 Civil 3D 기본 정지도구의 내부 메커니즘처럼, **단이 끝나는 지점 근처(예: 끝단 전방 3~5m 구간)에서 소단의 폭을 1m에서 0m로 서서히 좁히고 사면 구배를 자연스럽게 눕히며 비탈면에 흡수(Taper)시키는 3D 마감 브레이크라인**을 생성해야 합니다.


### [마감 토폴로지 구성 원리]
1. 단 링이 유효 구간에서 무효 구간으로 바뀌는 **최종 소멸점(Pinch-out Point)**을 찾습니다.
2. 그 소멸점으로부터 **이전 3m 구간**을 '테이퍼링 존(Tapering Zone)'으로 지정합니다.
3. 이 구간 안에서는 단의 폭(Bench Width)을 점진적으로 감소시켜, 최종 소멸점 위치에서는 **[사면 위 모서리]와 [소단 바깥 모서리]의 XY 좌표가 소수점 3자리까지 정확히 일치(폭 = 0)**하도록 만듭니다.
4. 두 모서리가 하나의 점으로 모이면서 폭이 0이 되면, 수직 단차를 유발하던 공간이 완전히 소거되므로 세로 빗살 삼각형이 기하학적으로 발생할 수 없게 됩니다.

## 3. 핵심 수정 코드 (C#)

기존 `ClipRingByGround` 알고리즘에 테이퍼링 마감 로직을 결합한 개전형 코드입니다.

```csharp
// [자문 #5 대응] 단 끝단을 부드럽게 오므려(Tapering) 비탈에 흡수시키는 3D 마감 헬퍼 함수
private static List<List<Point3>> ClipRingByGroundWithTaper(
    Coordinate[] coords, 
    Plane plane, 
    double zOff, 
    double benchWidth, 
    IGroundSurface ground, 
    bool up)
{
    var segments = new List<List<Point3>>();
    var cur = new List<Point3>();
    
    // 유효/무효 플래그 배열 사전 구축
    int count = coords.Length;
    bool[] isInside = new bool[count];
    double[] groundZ = new double[count];
    double[] benchZ = new double[count];

    for (int i = 0; i < count; i++)
    {
        benchZ[i] = plane.At(coords[i].X, coords[i].Y) + zOff;
        if (ground.TryGetElevation(coords[i].X, coords[i].Y, out double zg))
        {
            groundZ[i] = zg;
            isInside[i] = up ? (zg >= benchZ[i]) : (zg <= benchZ[i]);
        }
    }

    // 메인 루프 돌며 테이퍼링 마감 처리
    for (int i = 0; i < count; i++)
    {
        if (isInside[i])
        {
            Point3 currentPt = new Point3(coords[i].X, coords[i].Y, benchZ[i]);

            // 단 소멸점(Pinch-out)에 가까워지는지 전방 탐색 (예: 앞으로 5점 이내에 이탈이 일어나는가?)
            int lookAhead = 5;
            bool nearingExit = false;
            int exitIndex = i;
            for (int h = 1; h <= lookAhead; h++)
            {
                if (i + h < count && !isInside[i + h])
                {
                    nearingExit = true;
                    exitIndex = i + h;
                    break;
                }
            }

            if (nearingExit && benchWidth > 0)
            {
                // [핵심] 소단 외곽선일 경우, 소멸점에 가까워질수록 폭을 0으로 좁히기 위해 XY 좌표를 안쪽(사면선)으로 보정
                double ratio = (double)(exitIndex - i) / lookAhead; // 1.0에서 0.0으로 수렴
                currentPt = ApplyTaperOffset(currentPt, ratio, benchWidth);
            }

            cur.Add(currentPt);
        }
        else
        {
            if (cur.Count >= 2)
            {
                segments.Add(cur);
                cur = new List<Point3>();
            }
        }
    }

    if (cur.Count >= 2) segments.Add(cur);
    return segments;
}

private static Point3 ApplyTaperOffset(Point3 originalPt, double ratio, double maxWidth)
{
    // ratio가 0에 가까워질수록(소멸점에 인접할수록) 원래 위치에서 안쪽 사면선 방향으로 XY를 미세하게 이동시킴
    // 실제 구현 시에는 법선 벡터(Normal Vector)를 역으로 곱하여 안쪽으로 당겨줍니다.
    double currentWidth = maxWidth * ratio;
    
    // 개념 예시 (실제 프로젝트의 법선 구조에 맞게 구현):
    double newX = originalPt.X; // - (Normal.X * (maxWidth - currentWidth));
    double newY = originalPt.Y; // - (Normal.Y * (maxWidth - currentWidth));
    
    return new Point3(newX, newY, originalPt.Z);
}
```

## 4. 실무 표준 패턴 가이드 요약

1. **상수 고도(Constant-Z) 브레이크라인은 유지해야 하는가?**
   * **네, 무조건 유지해야 합니다.** 단 모서리의 일정한 고도 뼈대가 빠지면 단 자체가 울퉁불퉁해집니다. constant-Z를 유지하되, **끝점의 위치(XY)를 오므려서 해결**하는 것이 정석입니다.
2. **비탈면 채움 정점과의 간섭 문제:**
   * 빗살이 생기는 틈새 공간에 정점(`AddVertices`)을 아무리 촘촘히 밀어 넣어도, 브레이크라인이 뚝 끊긴 절벽 지형에서는 삼각망의 수직 찢김을 완벽히 막을 수 없습니다. 반드시 **[사면 위 선]과 [소단 바깥 선]이 3D 상에서 한 점으로 모여서 닫히는 종단 구조(End-Cap)**를 코드로 짜주셔야 합니다.

이 테이퍼링 로직을 반영하시면 소단 벨트가 지형 측면과 만날 때 칼로 자른 듯 수직으로 끝나지 않고, 자연스럽게 둥글게 감기며 비탈 속으로 스르륵 사라지는 완벽한 토목 정지면을 보실 수 있습니다. 빌드 후 스크린샷 피드백 부탁드립니다!
