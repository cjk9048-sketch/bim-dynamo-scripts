# [자문 요청 #7] daylight Outer전용 후 ① 초록선 2개 겹침 ② 사면 오목부 계단

## 0. 진행 상황
자문 #6(위상 용접 + daylight Outer 전용)을 적용해 **강제채움(webbing)·빗살이 대부분 사라짐**(큰 진전). 그러나 ① 화면 daylight 선이 2개로 겹쳐 보이고 ② 사면 **오목부(concave)** 에 작은 단끝 계단/탭이 남음.

## 1. 현재 구현 (자문 #3~#6 누적)
- 단 모서리 = `Buffer(d)` 동심 링, Z=designZ±k·H(constant-Z), daylight 1cm SafeZone 2D클립 → 3D Z-clip(pinch-out).
- **위상 용접(자문 #6)**: 단 레벨 k마다 사면위(top, d_top) arc와 소단바깥(toe, d_toe) arc를 구한 뒤, toe arc 양 끝점을 **snapTol(=max(5, period)≈6m) 이내 가장 가까운 top arc 끝점에 강제 스냅**(XY 일치, Z 보존). → 단끝 폭 0.
- **비탈면 채움 정점**: 단 사이 비탈을 ≈1m 오프셋 링 + Z-clip로 메워 정점(AddVertices)으로 추가.
- **daylight = Outer 트림 전용**(자문 #6): 브레이크라인으로 안 넣고, 파괴식 Outer 경계로만 바깥 삼각형을 잘라냄. (이전엔 Breakline+Outer였으나 toe 미세 톱니 때문에 Breakline 제거.)
- daylight 선(초록)은 별도 폴리라인으로 화면에 그림.

```csharp
// TIN 조립 (SurfaceBuilder)
foreach (var ring in benchRings) AddBreakline(tin, ring);  // 단 모서리(용접됨)
tin.AddVertices(fillVertices);                              // 비탈 채움 정점
tin.Rebuild();
// daylight = Outer 경계(파괴식). ★브레이크라인으로는 안 넣음(자문#6).
tin.BoundariesDefinition.AddBoundaries(daylightPc, 1.0, SurfaceBoundaryType.Outer, false);
tin.Rebuild();

// 위상 용접
private static void WeldBenchEnds(List<List<Point3>> topArcs, List<List<Point3>> toeArcs, double snapTol)
{
    foreach (var toe in toeArcs) {
        if (toe.Count < 2) continue;
        var s = FindClosestEnd(toe[0],  topArcs, snapTol);  // snapTol 이내 가장 가까운 top 끝점
        if (s.HasValue) { toe[0]  = new Point3(s.Value.X, s.Value.Y, toe[0].Z);  if (toe.Count>2) toe[1]  = Mid(toe[0],  toe[2]); }
        var e = FindClosestEnd(toe[^1], topArcs, snapTol);
        if (e.HasValue) { toe[^1] = new Point3(e.Value.X, e.Value.Y, toe[^1].Z); if (toe.Count>2) toe[^2] = Mid(toe[^1], toe[^3]); }
    }
}
```

## 2. 문제 ① — 초록 daylight 선이 2개로 겹쳐 보임
- **추정 원인**: daylight를 **브레이크라인에서 빼니**(Outer 전용), 화면에 그린 **daylight 폴리선**과 **실제로 잘린 표면의 가장자리(TIN 삼각형 모서리)** 가 더 이상 같은 선이 아니게 됨 → 두 선이 나란히/겹쳐 보임. (브레이크라인일 땐 표면 모서리가 daylight 선에 정확히 붙어 한 줄이었음.)
- **트레이드오프**: daylight=Breakline → 표면 모서리=daylight선(한 줄)이지만 **toe 미세 톱니**. daylight=Outer전용 → **톱니 없음**이지만 **두 줄(표면 모서리 ≠ 그린 선)**.
- 혼합 절·성토 부지라 전환부에서 daylight가 계획경계 근처로 들어왔다 나가는 것도 겹침을 키우는 듯.

## 3. 문제 ② — 사면 오목부(concave)에 단끝 계단/탭 잔존
- 볼록·직선부는 깨끗한데, **사면 오목부**에서 작은 단끝 탭/계단이 남음. 용접(snapTol≈6m)이 오목부에선 top/toe arc 끝점을 못 잡는 듯(오목부에선 Buffer 링이 압축돼 끝점 구조가 다르거나, top/toe 끝점이 멀거나 여러 조각).

## 4. 질문
1. **초록선 2개**: daylight=Outer전용을 유지하면서 (a) 화면 daylight 선을 **실제 잘린 표면 가장자리와 일치**시키려면? — daylight 점을 **정점(AddVertices)으로도** 넣어 표면 모서리가 그 선을 따라가게? 아니면 daylight 선을 안 그리고 **표면 경계(ExtractBorder)** 를 추출해 그리는 게 맞나? 톱니 없이 한 줄로 보이게 하는 표준 방법은?
2. **오목부 계단**: 오목부에서 단끝 용접이 안 되는 이유와, 오목 코너에서 단끝을 매끄럽게 닫는 방법은? (Buffer 동심 링은 오목부에서 어떻게 끝나는가, 용접 대상 arc를 어떻게 짝지어야 하나?)
3. 혹시 ①②를 한 번에 해결하는, daylight·단끝 처리의 더 단순·일관된 구성이 있는지?
