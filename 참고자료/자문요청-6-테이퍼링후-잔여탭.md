# [자문 요청 #6] 단끝 테이퍼링(자문 #5) 적용 후 — 남은 미세 탭/톱니

## 0. 한 줄 요약
자문 #5의 **단 끝단 테이퍼링(소단 바깥 모서리를 끝에서 소단폭→0으로 안쪽으로 당겨 사면 위 모서리에 수렴)** 을 구현했더니 **큰 세로 빗살은 사라졌으나**, ① **각 단이 옆에서 끝나는 자리에 작은 삼각 탭(sliver tab)** 과 ② **맨 끝단(daylight/toe) 미세 톱니** 가 남음. 완전히 닫는 방법을 묻고자 함.

## 1. 현재 구현 (자문 #3·#4·#5 모두 반영)
- 단 모서리 = 계획경계 `Buffer(d)` 동심 링, Z=designZ±k·H(constant-Z), daylight 1cm SafeZone 2D클립 → 3D Z-clip(원지반서 pinch-out).
- **자문 #5 테이퍼링**: 소단 바깥 모서리(toe, d=k·period)의 **열린 arc 양 끝 taperDist(≈3m) 구간**에서 각 점을 계획경계 방향(ClosestBoundary로 안쪽 방향 계산)으로 `benchWidth·(1−distFromEnd/taperDist)` 만큼 당김. 거리상 `d_toe − benchWidth = d_top` 이라 끝에서 사면 위 모서리(d_top) 거리에 수렴. Z=k·H 보존.
- daylight = Breakline + Outer(파괴식) 둘 다.
- 비탈면 채움 정점(AddVertices, 브레이크라인 아님): 단 사이 비탈을 ≈1m 오프셋 링 + Z-clip pinch로 메움.

```csharp
// 테이퍼링 핵심 (toe 열린 arc에만)
private static void TaperArcEnds(List<Point3> arc, IReadOnlyList<Point3> boundary,
    double benchWidth, double taperDist, GradingParams p)
{
    int n = arc.Count; if (n < 2) return;
    var s = new double[n];
    for (int i = 1; i < n; i++) s[i] = s[i-1] + Dist2D(arc[i], arc[i-1]);
    double total = s[n-1]; if (total < 1e-9) return;
    for (int i = 0; i < n; i++)
    {
        double distEnd = Math.Min(s[i], total - s[i]);
        if (distEnd >= taperDist) continue;
        double move = benchWidth * (1.0 - distEnd / taperDist);   // 끝에서 benchWidth, taperDist서 0
        var cb = PolygonGeometry.ClosestBoundary(boundary, arc[i].X, arc[i].Y, p.MiterConvex, p.MiterLimit);
        double dx = cb.Cx - arc[i].X, dy = cb.Cy - arc[i].Y, len = Math.Sqrt(dx*dx + dy*dy);
        if (len < 1e-9) continue;
        arc[i] = new Point3(arc[i].X + dx/len*move, arc[i].Y + dy/len*move, arc[i].Z); // Z 보존
    }
}
```

## 2. 남은 문제 (스샷 기준)
1. **단 끝 작은 삼각 탭**: 테이퍼로 toe를 top 거리(d_top)까지 안쪽으로 당겼지만, **toe arc 끝점과 top arc 끝점이 서로 다른 링에서 독립 생성**돼 XY가 정확히 일치하지 않음 → 끝에 작은 슬리버(높이 k·H의 작은 삼각 탭)가 남음. (자문 #5가 "두 모서리 XY를 소수점 3자리까지 일치" 강조했으나, 현재는 거리만 맞췄고 점이 안 겹침.)
2. **맨 끝단 toe 톱니**: daylight 브레이크라인(원지반 높이, 실제 TIN이라 미세 굴곡)이 dense하게 들어가 toe 가장자리가 미세 톱니. 단/채움 pinch 점들과 staggered.
3. **★ 테이퍼링의 역효과(중요)**: 테이퍼링 적용 후, 오류가 **맨 끝단(외곽)뿐 아니라 부지 안쪽(단↔단 전환부)까지 퍼짐.** 각 단이 옆에서 끝나는 자리마다(외곽이 아니라 내부의 단 끝들 포함) 높이 k·H의 작은 삼각 탭이 생김. 즉 toe 끝점을 안쪽으로 당기는 처리가 **모든 단 끝(내부 포함)에 새 슬리버를 만들어** 오히려 악화. → 테이퍼링이 이 아키텍처(독립 링 + Z-clip)에 맞는 처리인지 의문.
